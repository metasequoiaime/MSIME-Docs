# macOS 使用指南

水杉 macOS 前端使用原生输入法界面，支持 macOS 12 及以上版本。本文按 2026-09-06 的 Apple 源码整理；安装包功能以对应 Release 为准。iOS 键盘仍在开发中，不能用 macOS 安装包安装到 iPhone 或 iPad。

## 下载与安装

从 [Apple Releases](https://github.com/metasequoiaime/MSIME-Apple/releases) 下载对应版本的 macOS universal ZIP 或 PKG。universal 包面向 Apple Silicon 与 Intel Mac。文件名中的 `-update.zip` 是自动更新载荷，手动安装请选择普通 ZIP 或 PKG。

1. 下载归档及同名 `.sha256` 文件，在下载目录用 `shasum -a 256 -c 文件名.sha256` 校验；把“文件名”替换为实际下载名称。
2. ZIP 解压后运行其中的 `Install.command`；PKG 则双击进入系统安装器。两种方式都安装到当前用户的 `~/Library/Input Methods`，PKG 可能请求管理员授权。
3. 安装器会尝试注册并启用输入法。未出现时，到“系统设置 → 键盘 → 文本输入 → 编辑”中添加水杉；较旧系统的入口名称可能不同。
4. 在菜单栏输入源中选中水杉，打开文本框输入 `nihao`，按空格选词。

带 `-unsigned` 的包是明确标注的未签名测试产物。按发布说明和系统提示处理；ZIP 安装器可能要求输入 `I UNDERSTAND`。如果系统仍未刷新输入源，保存工作后注销并重新登录。

## 常用操作

| 操作 | 按键或入口 |
| --- | --- |
| 选择候选 | 空格选首选；`1`～`9` 选择对应候选，也可点击候选 |
| 提交原始字母 | `Enter` |
| 修改或取消 | `Backspace` 退格；`Esc` 取消 |
| 中英文切换 | `Shift + Space`，或输入法菜单；快捷键可在设置关闭 |
| 半角／全角 | `Option + Shift + H` |
| 简体／繁体 | 输入法菜单或悬浮状态栏 |
| 翻页 | 在设置选择 `-` / `=`、`[` / `]` 或 Page Up / Page Down |

切换到英文时会先上屏正在进行的中文组词，后续按键直接交给应用。全角模式主要转换未组词时输入的 ASCII 字母、数字、标点和空格。简繁转换改变候选展示和上屏结果，不改写词库键值。

## 设置与候选窗口

通过输入法菜单、悬浮状态栏齿轮，或发布 ZIP 中的 `Open Settings.command` 打开设置。常用选项包括：

- **输入方案**：全拼、小鹤双拼、86 五笔；五笔可配置唯一四码候选自动上屏。
- **候选外观**：横排／竖排，每页 5、7 或 9 项，小／标准／大号字体。
- **双拼键位提示**：显示小鹤键位和零声母对照；上屏或取消后隐藏。
- **辅助码**：全拼和双拼分别设置开关与方案，可选蓝天小雨点、自然码、首右 2.0、首右 Plus、小鹤；候选旁显示辅助码提示。
- **输入行为**：全拼纠错、中文标点、词频学习以及悬浮状态栏显示。

设置按当前用户保存。正在进行的组词沿用开始时的设置，新设置在上屏或取消后用于后续输入。辅助码追加在完整拼写之后；初次使用建议先开启提示，再练习完整拼写加形码的输入方式。

## 本地快捷模式

在“词库与数据”中开启“启用本地输入模式”（默认关闭），全拼或双拼下无活动组词时可使用：

| 快捷键 | 用途 | 示例 |
| --- | --- | --- |
| `Shift + U` | Unicode 码点 | `4e00` 对应“一” |
| `Shift + T` | 日期、时间、星期 | `rq`、`sj`、`xq` |
| `Shift + K` | 快捷短语 | 输入词库中已有的字母编码 |
| `Shift + J` | 超级简拼 | `nh` 检索“你好”等候选 |

关闭总开关时，这些组合照常输入大写字母。当前 macOS 安装包不附带额外表情、英文和日语数据，因此不要照搬 Windows/Linux 的 E、M、Y、R 模式。表情可通过输入法菜单或工具菜单打开 macOS“表情与符号”查看器。

## 语音与数据

录音配置、`Control + Option + V` 快捷键、取消操作和麦克风权限见 [macOS 语音输入](macos-voice.md)。云端识别上传音频，本地 Whisper 使用用户选择的模型；开启文本整理后，转写文本仍会发往整理服务。

普通键盘输入与候选学习在本机处理。学习数据和可写词库位于 `~/Library/Application Support/metasequoiaime/`，设置保存在当前用户的 macOS 偏好设置中。关闭候选学习只影响后续组词；“清除学习数据”会清除本地学习数据库并恢复随包词库，请先确认不再需要这些记录。备份数据目录前先切换到其他输入法并退出水杉，避免复制正在写入的数据库。语音密钥在钥匙串中，不包含在普通数据目录备份内。

## 更新与卸载

输入法菜单和设置面板均有“检查更新…”入口。自动更新使用 Sparkle；普通 ZIP、PKG 与自动更新载荷的区别见前面的安装说明。更新失败时保留错误信息，到同一官方 Release 页面核对安装版本与可用产物。

卸载使用发布 ZIP 中的 `Uninstall.command`；PKG 安装后也可运行：

```sh
"$HOME/Library/Input Methods/MetasequoiaIME.app/Contents/Resources/Uninstall.command"
```

默认将当前用户的输入法移入废纸篓，保留偏好与学习数据。脚本要求输入 `REMOVE METASEQUOIAIME` 确认。只有确实要移除数据时才加 `--remove-user-data`；该选项会将偏好和学习数据一并放入废纸篓中的恢复文件夹。完成后注销，让系统刷新输入源缓存。

## 常见问题与反馈

- **输入源未出现**：确认安装在当前登录用户目录，检查系统是否拦截应用，在文本输入设置中手动启用，必要时注销登录。
- **快捷键输入大写字母**：确认本地输入模式已开启，且当前没有未完成的组词。
- **设置没有立即生效**：先上屏或取消当前组词，再重新输入。
- **语音无结果**：检查麦克风权限、设备、模型或服务配置；移动光标、继续键盘输入或切换窗口会取消请求。

问题提交到 [Apple Issues](https://github.com/metasequoiaime/MSIME-Apple/issues)，附 macOS 与输入法版本、芯片架构、宿主应用和最小复现步骤。共享材料前移除实际输入内容和凭据。更完整的数据说明见 [Apple 隐私说明](https://github.com/metasequoiaime/MSIME-Apple/blob/main/PRIVACY.md)。
