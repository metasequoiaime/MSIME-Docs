# macOS 语音输入

该功能已合入 Apple 源码主分支；使用安装包时，请先确认版本的输入法菜单包含「语音输入设置…」。iOS 键盘目前没有语音入口。

安装、日常输入和数据管理见 [macOS 使用指南](macos.md)。

## 配置

在水杉输入法菜单打开「语音输入设置…」，选择云端识别或本地 Whisper。

- 云端：填写兼容语音转写接口的 HTTPS 地址、模型名称和 API 密钥。
- 本地：选择已下载的 Whisper 模型文件。模型由用户自行准备，输入法不会自动下载。
- 文本整理：按需单独开启并填写整理服务、模型和密钥。即使识别使用本地模型，启用整理后仍会将转写文本发送到整理服务。

密钥保存在系统钥匙串中，按服务来源区分；修改服务地址后需要重新填写密钥。保存设置后，回到需要输入文字的应用并切换到水杉。

## 录音与上屏

按 Control+Option+V 开始录音，再按一次结束并识别；也可使用输入法菜单中的「语音输入」。第一次使用会请求麦克风权限。录音最长 60 秒，识别完成后文本插入原来的输入位置。

按 Esc、继续键盘输入或切换输入窗口会取消本次请求。光标位置改变后，迟到的结果也不会插入新位置。已经开始的本地 Whisper 推理可能继续计算，但取消后不会提交结果。

## 数据与权限

录音在本次请求的内存中保存，不生成录音文件。云端识别会上传本次音频，文本整理会上传转写文本；服务收到的数据无法通过取消操作收回。

如果无法录音，请在 macOS 系统设置的「隐私与安全性 → 麦克风」中检查水杉的权限，并确认有可用录音设备。识别失败时检查所选模型文件或服务地址、模型名称及账户权限。隐私详情见 [Apple 隐私说明](https://github.com/metasequoiaime/MSIME-Apple/blob/main/PRIVACY.md)。
