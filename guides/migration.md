# 从其他输入法迁移

从搜狗、微软拼音或 Rime 换到水杉，最麻烦的一步是把积累多年的自造词带过来。本文说明各家能导出什么、水杉需要什么格式、以及怎么转换。

本文按 2026-09-06 核对的源码与各平台指南整理。转换器与词库格式规范都在仓库里，可以对着核对。

## 水杉需要什么格式

批量导入接受 **UTF-8 纯文本**（`.txt`），可带 BOM，换行 LF 或 CRLF 均可，**不要加表头**。列与列之间**只能用真正的 Tab**（`\t`），不能用空格、逗号或分号。

全拼词库每行三列，顺序固定：

```text
你好	ni'hao	10
西安	xi'an	10
水杉输入法	shui'shan'shu'ru'fa	1
```

三条硬性要求：

- 全拼必须是**完整音节**，不能用简拼；
- 音节数必须等于词语的字数；
- 权重是非负整数，**不能省略**。

推荐用 `'` 手动分音节。没有 `'` 时输入法会自动切分，但 `西安` 这类词会被切成 `xian`，所以务必写成 `xi'an`。

五笔与英文词库的格式，以及导入入口的位置，见[Windows 指南的词库一节](windows.md#词库)。Linux 与 macOS 的入口见各自的指南。

## 用转换器

引擎仓提供了一个转换脚本，支持三种纯文本输入：

```sh
git clone https://github.com/metasequoiaime/MSIME-Engine.git
cd MSIME-Engine/dictionary
python3 -m pip install -r requirements.txt          # 只有 words 模式需要，用于生成拼音
python3 tools/convert_user_dictionary.py --format <格式> <源文件> --output out.txt
```

| `--format` | 输入形状 | 典型来源 |
| --- | --- | --- |
| `rime` | `*.dict.yaml`，`...` 分隔符之后的 `词语<TAB>编码[<TAB>权重]` | Rime 自定义词库 |
| `csv` | 每行 `词语,拼音` | 搜狗导出的逗号分隔文本 |
| `words` | 每行一个词，无读音；用 pypinyin 生成拼音 | 任何只有词表的来源 |

`--weight N` 指定统一权重（默认 1）。转换结果写到 `--output`，跳过的条目连同原因打印到标准错误，例如：

```
skipped '你好': reading 'nihao' has 1 syllable(s) but the word has 2 character(s); add ' between syllables
converted 1274 entries, skipped 3
```

单条坏行不会让整次转换失败。

### 有意不做的两件事

**不解析搜狗细胞词库（`.scel`）。** 那是私有二进制格式，凭猜测重新实现出来的解析器没法验证对错。请先在搜狗客户端里把词库导出成文本，再用上面的 `csv` 或 `words` 模式。

**不猜测未分音节的连写读音。** `xian` 既可能是 `xi'an` 也可能是 `xian`，`nihao` 同理。遇到这种读音，转换器会跳过并说明原因，而不是劈开一个可能错的音节。要么在源文件里补上 `'`，要么用 `words` 模式丢掉原读音、由 pypinyin 重新生成。

## 各家能导出什么

### 搜狗拼音

搜狗的**细胞词库**（`.scel`）是从官方词库仓下载的专业领域词库，不是你自己的词。这类词水杉的自带词库基本已经覆盖，通常不需要迁移；真正值得带走的是你自己造的词。

在搜狗客户端的词库管理里把**用户词库**导出成文本。导出格式随版本变化，常见的是每行 `词语,拼音` 或只有词语一列——分别对应转换器的 `csv` 与 `words` 模式。导出前先打开文件看一眼实际是哪种，不要按记忆假设。

如果导出的拼音是 `nihao` 这种未分音节的连写，直接用 `words` 模式：丢掉原读音、由 pypinyin 重新生成，比手工补几千个 `'` 现实得多。

### 微软拼音

微软拼音的自学习词库不提供直接的文本导出入口，能导出的是**自定义短语**。它的语义与水杉的「快捷短语」对应，不是全拼词库——导入入口在「实用功能 → 快捷短语」，格式见 Windows 指南对应小节，不要塞进全拼词库的批量导入。

自学习积累的词频没有导出路径。可行的做法是把常用词整理成一份词表，用 `words` 模式转换后导入；权重可以用 `--weight` 统一给一个较高的值，让它们优先于自带词库。

### Rime

Rime 的自定义词库 `*.dict.yaml` 是纯文本，直接用 `rime` 模式转换即可。

注意 Rime 的编码列不一定是全拼——如果你用的是双拼、五笔或注音方案，那一列是对应方案的编码，转换出来会被水杉的导入器拒绝，或者更糟，被当成拼音接受但对不上。这种情况下用 `words` 模式，只取词语、重新生成拼音。

Rime 的**用户词典**（`*.userdb`）是数据库目录，不是文本。用 Rime 自带的 `rime_dict_manager` 导出成文本之后再转换。

## 导入之后

- 导入不会覆盖已有条目：**已存在的词条会跳过**，原有权重保留。所以先导入再调频，顺序反了会白调。
- 部分失败时会返回行号。按行号检查 Tab、列数、权重和音节数，修好失败行重新导入即可，已成功的条目不会重复。
- 导入的是你的用户词库，卸载时会随 `msime_user.db` 一起删除。迁移完成后建议先导出一份备份。
