# 从其他输入法迁移

从搜狗、微软拼音或 Rime 换到水杉，最麻烦的一步是把积累多年的自造词带过来。本文说明各家能导出什么、水杉需要什么格式、以及怎么转换。

本文按 2026-10-01 核对的 Windows 正式版 v0.9.3 源码与各平台指南整理，下文的导入格式、入口名称和默认值都以 Windows 版为准。导入规则在 [msime-windows](https://github.com/metasequoiaime/msime-windows) 的 `server/src/settings/dictionary_validation.cpp` 与 `dictionary_manager.cpp` 里，可以对着核对。

## 水杉需要什么格式

批量导入读取纯文本（`.txt`；Rime 词库也可以直接选 `.yaml`）。推荐 **UTF-8**，可带 BOM；带 BOM 的 UTF-16 和 GBK/GB18030 编码也能识别。换行 LF 或 CRLF 均可，**不要加表头**，空行和以 `#` 开头的注释行会被跳过。列与列之间**只能用真正的 Tab**（`\t`），不能用空格、逗号或分号。

全拼词库每行两列或三列，顺序固定为词语、全拼、权重：

```text
你好	ni'hao	10
西安	xi'an	10
水杉输入法	shui'shan'shu'ru'fa	1
```

三条硬性要求：

- 全拼必须是**完整音节**，不能用简拼；
- 音节数必须等于词语的字数；
- 权重是非负整数；可以省略，省略时为 `10000`。

推荐用 `'` 手动分音节。没有 `'` 时（空格不算分隔，会先被去掉）输入法会自动切分，并优先选择音节数等于字数的切法，所以 `西安` 写成 `xian` 也会按 `xi'an` 导入；但音节数相同的不同切法（例如 `fang'an` 与 `fan'gan`）无法靠字数分辨，这类词仍要写上 `'`。

五笔与英文词库的格式，以及导入入口的位置，见[Windows 指南的词库一节](windows.md#词库)。Linux 与 macOS 指南目前没有本地词库批量导入的说明，本文的格式与入口只适用于 Windows 版。

## 按来源选择导入方式

旧版本文让你克隆引擎仓运行 `convert_user_dictionary.py`。那个仓库（msime-engine）已归档，脚本不再维护；它处理的三种纯文本来源，Windows 版现在都能在设置里导入，不再需要转换脚本（逗号分隔文本只需先把逗号换成 Tab）：

| 来源形状 | 怎么导入 | 典型来源 |
| --- | --- | --- |
| `*.dict.yaml`，`...` 分隔符之后的 `词语<TAB>编码[<TAB>权重]` | 「词库 → 全拼词库」的「批量导入」直接选择该文件 | Rime 自定义词库 |
| 每行 `词语,拼音` | 把每行第一个逗号换成 Tab 后「批量导入」；或只保留词语一列，按下一行处理 | 搜狗导出的逗号分隔文本 |
| 每行一个词，无读音 | 「批量导入纯汉字词组(e.g.人名)到拼音词库」，自动注音，权重统一为 `10000` | 任何只有词表的来源 |

导入结束后会提示成功、跳过（已存在）和失败的条数，失败的前 5 行带行号和原因，例如：

```
成功导入 1274 条，跳过 2 条（已存在），失败 1 条。第 5 行：全拼必须由拼音表中的完整音节组成，不能使用简拼
```

单条坏行不会让整次导入失败。纯汉字词组导入只接受全是汉字的行，含字母、数字、标点或扩展区生僻字的行会失败。

### 仍然不能直接导入的格式

**搜狗细胞词库（`.scel`）。** 那是私有二进制格式，凭猜测重新实现出来的解析器没法验证对错。请先在搜狗客户端里把词库导出成文本，再按上表导入。

## 各家能导出什么

### 搜狗拼音

搜狗的**细胞词库**（`.scel`）是从官方词库仓下载的专业领域词库，不是你自己的词。这类词水杉的自带词库基本已经覆盖，通常不需要迁移；真正值得带走的是你自己造的词。

在搜狗客户端的词库管理里把**用户词库**导出成文本。导出格式随版本变化，常见的是每行 `词语,拼音` 或只有词语一列——分别按上表的逗号文本和纯词表处理。导出前先打开文件看一眼实际是哪种，不要按记忆假设。

如果导出的拼音是 `nihao` 这种未分音节的连写，换成 Tab 后也可以直接导入：输入法会按字数选择切法。只有音节数相同、切法不同的词（如 `fangan`）可能切错；在意的话只保留词语一列，用纯汉字词组导入重新注音。

### 微软拼音

微软拼音的自学习词库不提供直接的文本导出入口，能导出的是**自定义短语**。它的语义与水杉的「快捷短语」对应，不是全拼词库——导入入口在「实用功能 → 快捷短语」，格式见 Windows 指南对应小节，不要塞进全拼词库的批量导入。

自学习积累的词频没有导出路径。可行的做法是把常用词整理成一份词表，用「批量导入纯汉字词组」导入，权重统一为 `10000`；需要其他权重时，写成 `词语<TAB>全拼<TAB>权重` 三列，用「批量导入」。

### Rime

Rime 的自定义词库 `*.dict.yaml` 是纯文本，可以直接在「批量导入」里选择：`---` 到 `...` 之间的 YAML 头和 `#` 注释行会被跳过，第三列必须是非负整数，省略时按默认权重 `10000` 处理；`99.93%`、`0.5` 这类百分比或小数权重会导致该行导入失败，先删掉第三列或改成整数。Rime 编码列用空格分音节，导入时空格会被去掉后重新切分；想保住 `fan gan` 这类切法，先把编码列中的空格替换成 `'`。

注意 Rime 的编码列不一定是全拼——如果你用的是双拼、五笔或注音方案，那一列是对应方案的编码，导入全拼词库时会被拒绝，或者更糟，被当成拼音接受但对不上。这种情况下只保留词语一列，用纯汉字词组导入重新注音。86 五笔方案的词库可以在「五笔词库」页用「批量导入」导入。

Rime 的**用户词典**（`*.userdb`）是数据库目录，不是文本。用 Rime 自带的 `rime_dict_manager` 导出成文本之后再「批量导入」。`rime_dict_manager` 导出的文本就是 `词语<Tab>编码<Tab>次数`，可以直接导入。同步目录里的 `*.userdb.txt` 快照则是 `编码<Tab>词语<Tab>c=…`，编码在前，要先调换前两列；调换后第三列的 `c=…` 按默认权重 `10000` 处理。

## 导入之后

- 导入不会覆盖已有条目：**已存在的词条会跳过**，原有权重保留。所以先导入再调频，顺序反了会白调。
- 部分失败时会返回行号。按行号检查 Tab、列数、权重和音节数，修好失败行重新导入即可，已成功的条目不会重复。
- 导入的是你的用户词库，卸载时会随 `msime_user.db` 一起删除。迁移完成后建议先导出一份备份。

## 反过来：从水杉导出

「词库」页的「导出词库」可以分别导出拼音、五笔和英文用户词库，格式与导入格式相同；拼音用户词库只导出多字词。这份文件既是备份，也是换到别的输入法时的迁移源。快捷短语的导出入口在「实用功能 → 快捷短语」。
