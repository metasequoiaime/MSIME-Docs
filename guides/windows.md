# 水杉输入法文档

水杉输入法（Metasequoia IME）是一款面向 Windows 10、Windows 11 的开源中文输入法，采用纯 TSF 方案。目前支持全拼、双拼、86 五笔和日语罗马音输入，也提供辅助码、云候选、AI 联想、语音输入、手写输入和快捷短语等功能。

本文按 2026-10-01 核对的 Windows 源码（v0.9.3）整理。安装包可能早于源码，找不到某个选项时请先查看该版本的发布说明。

## 下载安装

请前往[官网下载页面](https://msime.app/download/)获取最新版本，并按对应版本的 GitHub Release 说明完成安装。不同版本的安装方式和功能可能会有变化，以发布说明为准。

安装程序会先检查 Microsoft Edge WebView2 Runtime 和 Visual C++ 2015–2022 x64 运行库，缺少时给出说明和下载入口。向导中可以选择数据目录，用来存放词库、配置和皮肤，默认是 `%LOCALAPPDATA%\metasequoiaime`，也可以放到其他磁盘；升级安装时改到新位置会迁移现有数据。首次安装还会显示“联网功能”页，询问是否启用云候选，详见下文“云候选”。本文后面的路径都以默认数据目录为例，改过位置时请换成自己的数据目录。

安装完成后，安装程序会启动 Server（`MetasequoiaImeServer.exe`）和 Watchdog（`MetasequoiaImeWatchdog.exe`），可以在任务管理器中确认。Watchdog 会在登录时自动运行并拉起 Server，Server 意外退出后也会由它重新启动。按 `Win + Space` 切换到水杉输入法后即可开始使用。

### 安装后无法使用或设置窗口闪退

如果安装完成后无法正常切换到水杉输入法，或者打开设置窗口后立即退出，请先检查 Microsoft Visual C++ 运行库。水杉输入法的 Server 和设置程序均为 64 位程序，需要安装最新的 **Microsoft Visual C++ 2015–2022 Redistributable（x64）**。

请注意，64 位 Windows 可以同时安装 x86 和 x64 两套 Visual C++ 运行库。只安装或更新 `vc_redist.x86.exe` 不能满足水杉输入法的运行要求；即使“已安装的应用”中已经出现 Microsoft Visual C++ Redistributable，也要确认名称中包含 **x64**。

典型现象包括：

- 使用 `Win + Space` 切换后输入法没有响应；
- Metasequoia IME Server 启动后反复退出；
- 设置窗口打开后立即消失；
- Windows 事件查看器记录 `MetasequoiaImeServer.exe` 或 `MetasequoiaImeSettings.exe` 在 `MSVCP140.dll` 中以 `0xc0000005` 异常退出。

遇到上述情况时，请直接下载并安装微软官方的 [`vc_redist.x64.exe`](https://aka.ms/vc14/vc_redist.x64.exe)。如果安装程序提供“修复”选项，请执行修复；安装完成后建议重新启动 Windows，再运行水杉输入法。不要用 `vc_redist.x86.exe` 代替 x64 版本。

如果安装最新 x64 运行库并重启后仍无法使用，请先保留错误提示、事件查看器记录和复现步骤，再按本文“反馈”一节提交问题。不要先卸载清理，以免丢失定位所需的信息。

## 开始输入

在记事本等文本框中切换到水杉，确认处于中文状态和全拼方案，输入 `nihao`，按空格选择高亮候选；也可按候选前的数字选择。`Esc` 取消，`Enter` 提交原始字母串。通过输入法右键菜单或悬浮工具栏的设置入口调整方案。

## 设置窗口

下面按照设置窗口左侧功能区从上到下的顺序逐项说明。配置修改后会自动保存，一般不需要再点“应用”或“确定”。

### 外观

#### 候选窗口预览

同时显示横排和竖排候选窗的效果。更改字体、字号、颜色、主题或排列方式时，可以先在这里查看大致效果。

#### 界面渲染与光标跟随

“界面渲染”可选 Direct2D（原生）或 WebView2，用于候选窗、悬浮工具栏和托盘菜单。更改后需重启输入法进程才会生效，可以直接点击下方“重启输入法进程”一栏的“重启”。设置页仍需要 WebView2 Runtime；表情、手写和屏幕键盘面板是原生窗口，不依赖它。

“设置窗口后台驻留”决定关闭设置窗口后进程保留多久，可选“关闭后立即退出”、1 分钟到 1 小时或“一直驻留”。驻留期间再次打开无需等待加载，但会继续占用内存。

“候选窗口跟随光标”关闭后，候选窗保持本次出现时的初始位置，直到窗口消失。

#### 固定候选徽标

开启后，为手动固定位置的候选显示角标，便于辨认。样式可选回形针、图钉或圆点。

#### 候选窗样式

- **候选窗主字体**：候选窗优先使用的西文字体，主要影响拉丁字母、数字和标点。列表来自当前系统已经安装的字体。
- **候选窗补充字体**：主字体缺少的字符（例如汉字）按这里的顺序依次回落，最后使用系统字体。可以点击“+”添加多个字体，列表同样取自系统字体。
- **候选窗字号**：可选 `12`～`32` 像素。字号越大，候选窗占用的空间也越大。
- **候选窗预编辑字号**：单独调整候选窗顶部输入串的大小，可选 `12`～`32` 像素。
- **候选文字颜色**：点击色块可以自定义候选文字颜色；点击“跟随主题”后，文字颜色会重新随深色、浅色主题自动变化。
- **每页候选项数量**：可选 `3`～`9` 项。这里只改变一页显示多少项，不会减少实际候选结果。

#### 主题模式

全局主题可选“深色”“浅色”或“跟随系统”。“跟随系统”会使用 Windows 当前的应用颜色模式。

#### 各界面主题

设置界面、候选窗口、悬浮工具栏、菜单、表情面板、屏幕键盘、手写识别板和语音输入弹出条都可以单独指定主题。每一项都有“跟随全局”“深色”和“浅色”三个选项。

“跟随全局”表示使用上面的“主题模式”；单独选择深色或浅色后，该界面不再随全局主题切换。

#### 候选项排列方式

“横向”会把候选项排在一行，“纵向”则逐行显示。两种样式只改变候选窗布局，不影响候选排序。

#### 行内预编辑

行内预编辑是光标所在应用中显示的未上屏输入串。

- **原始按键**：显示实际键入的字母。
- **拼音分词**：显示输入法切分后的拼音。
- **不显示**：应用内不显示预编辑串，候选窗仍可照常使用。

#### 候选窗预编辑

控制候选窗顶部是否显示输入串。“拼音分词”会显示切分后的拼音，“不显示”会隐藏这一行。它和“行内预编辑”相互独立，可以分别设置。

### 输入

#### 输入模式与日语

“输入模式”可选中文或日文。中文下再选择全拼、双拼或五笔；日文使用罗马音输入，候选包含平假名、片假名和日语词库结果，日文下 `-` 用来输入长音符 `ー`，`-` / `=` 都不再用于翻页，请改用其他翻页键。切回中文时保留原有中文方案。只需临时输入日语时，可以使用“实用功能”中的 R 模式。

#### 输入方案

- **全拼**：按完整拼音输入。
- **双拼**：用两个按键组合声母和韵母。选择后，下方的“双拼方案”才有实际作用。
- **五笔**：使用五笔字型输入。当前设置窗口提供 86 五笔。

#### 双拼方案

可选小鹤双拼、自然码双拼、首道双拼、微软双拼、搜狗双拼、紫光双拼、智能ABC、国标双拼和拼音加加。切换方案会改变双拼键位映射，不会改动全拼和五笔设置。

#### 自定义双拼

把 UTF-8 编码的 `.toml` 双拼方案文件放进数据目录下的 `shuangpin\custom` 文件夹，点击“刷新方案”后即可在“双拼方案”中选择；页面提供“打开目录”入口。文件里用 `zero_initial_rule` 选择零声母规则，在 `[initials]` 和 `[finals]` 中写声母、韵母对应的按键，完整写法见[示例文件](https://github.com/metasequoiaime/msime-windows/blob/develop/docs/custom-shuangpin.example.toml)。有错误的方案显示为灰色，鼠标悬停可查看原因。修改正在使用的方案文件后，需要切换一次方案或重启输入法才会生效。

#### 五笔方案

当前可选项为“86 五笔”。四码只有唯一候选时自动上屏；四码之后继续输入，前一个字会被顶上屏。

- **拼音混输**：同一串字母同时查五笔码表和全拼，五笔候选在前，拼音候选在后。
- **z 键通配**：开启后 `z` 可匹配码表中该位置的任意字母（含首位），常用于首码不确定时起头。

#### 翻页方式

这里可以同时勾选多组按键：

- `-` / `=`：上一页 / 下一页。
- `,` / `.`：上一页 / 下一页。
- `[` / `]`：上一页 / 下一页。
- `Shift + Tab` / `Tab`：上一页 / 下一页。
- `Page Up` / `Page Down`：上一页 / 下一页。
- `↑` / `↓`：在候选项之间移动高亮位置。
- 鼠标滚轮：滚动候选窗翻页。需要开启 Windows 设置中的“当我悬停在非活动窗口上方时滚动它们”，否则滚轮不会到达候选窗。

取消某一项后，对应按键不再用于候选操作，适合避开自己常用软件中的按键习惯。`[` / `]` 和 `-` / `=` 也可以用作“以词定字”的按键，已勾选用于翻页的键组不能再选作以词定字。

#### 输入纠错

全拼输错时给出纠正候选，两项默认关闭。开启后预编辑仍显示原始输入，纠正结果只出现在候选中。

- **乱序纠错**：相邻字母顺序打错时纠正，例如 `sahng` → `shang`（上）。
- **邻键纠错**：误触相邻按键时纠正，例如 `shabg` → `shang`（上）。

#### 模糊音

开启总开关后，勾选的两个读音互相匹配，例如勾选 `z ⇄ zh` 后输入 `zhang` 也能命中 `zang` 开头的词，全拼和双拼均生效。声母可选 `z ⇄ zh`、`c ⇄ ch`、`s ⇄ sh`、`n ⇄ l`、`f ⇄ h`、`r ⇄ l`，韵母可选 `an ⇄ ang`、`en ⇄ eng`、`in ⇄ ing`、`ian ⇄ iang`、`uan ⇄ uang`。

#### 候选词翻译

开启后，在横排和竖排候选窗口中显示候选与目标语种的互译，每项最多两个简短释义。释义用于展示，上屏内容仍是候选文字；候选窗显示时按 `Ctrl + Enter` 可以改为上屏高亮候选右侧的译文，有多条译文时会先列出供选择。

目标语种可选英语、法语、日语、西班牙语、俄语、德语和韩语。英语优先使用本地词库，本地未命中时使用所选在线服务：腾讯云 TMT 填写 SecretId、SecretKey；小牛翻译填写 APP ID 和 API Key；自定义 DeepLX 填写完整的 POST 接口地址和可选的 Bearer API Key。凭据只保存在本机配置文件中，填好后可以点击“测试配置”检查。在线翻译会把待翻译候选发送给配置的服务。

自定义本地释义可写入 `%LOCALAPPDATA%\metasequoiaime\custom_translations.txt`：UTF-8 文本，每行用 Tab 分隔源词和译文，例如“你好”、Tab、“hello”。源词含汉字时为中译英，全是英文时为英译中。以 `#` 开头的行和空行忽略；相同源词以最后一条为准，优先于内置释义。修改后重启输入法生效。

#### 以词定字

开启后，按所选键组的左键上屏当前高亮候选的第一个汉字，按右键上屏最后一个汉字。键组可选 `[` / `]` 或 `-` / `=`，已勾选用于翻页的键组不能选。遇到单字难找、但相关词组很容易输入时，这个功能会比较顺手。

#### Esc 保留已选词

默认关闭。开启后，造词时第一次按 `Esc` 只清除还没选的拼音、保留已选的词，再按一次 `Esc` 才整体取消，与小狼毫的行为一致。

#### 固定标点状态

可在“跟随中英文状态”“始终使用中文标点”和“始终使用英文标点”三者中选一项。选择后两项之一时，切换中英文输入仍使用指定的标点状态。

#### 智能标点

在中文标点状态下自动转换标点。新安装默认关闭；打开总开关后，再按需开启下面四项：

- **中文标点后按空格转换**：输入 `。，！？；：、` 以及单独出现的 `“ ”`、`【 】`、`《 》`、`（ ）` 后按空格，转为对应的英文标点。“成对标点自动补全”一起补出的成对符号不转换。
- **同键转回中文**：转换或直出的英文标点，2 秒内再按同一标点键会转回中文。
- **数字后直出**：数字后输入 `,`、`.`、`:` 直接输出英文标点，例如 `3.14`。
- **字母后直出**：字母后输入 `,`、`.`、`:` 直接输出英文标点。

#### 成对标点自动补全

输入左侧括号、引号等成对符号时，自动补上右侧符号，并把光标放在两者中间。

#### 常用输入状态和中文标点

- 按 `Ctrl + .` 可以在中文标点和英文标点之间切换，也可以点击悬浮工具栏上的“中英文标点”。
- 按 `Ctrl + Shift + Space` 可以切换全角和半角字符。
- 在中文模式下按 `Ctrl + Shift + E`，可以进入或退出独立的英文候选输入模式。这个模式与下方的“中英混输”不同：中英混输是在拼音候选中补充英文，英文候选模式则专门按英文词库匹配当前字母串。
- 中文标点状态下，按反斜杠键 `\` 输入顿号 `、`。这是顿号对应的直接按键，不需要先打开符号面板。
- 其他常见对应关系包括：键盘左上角的反引号键输入间隔号 `·`，`Shift + 6` 输入省略号 `……`，`Shift + -` 输入破折号 `——`，`Shift + ,` / `Shift + .` 输入书名号 `《` / `》`。

已经有候选时，输入中文标点通常会先上屏当前高亮候选，再紧跟标点。如果只是想取消当前输入，请按 `Esc`。

#### 中英混输

开启后，在中文输入状态下也会根据字母串给出英文候选。触发字符数可以设置为 `1`～`8`，默认为 `5`，达到设定长度后才补充英文候选，适合在中文句子中穿插英文单词。

#### emoji 与颜文字混输

分别开启后，可在普通中文候选中补充匹配的 emoji 和颜文字。英文、emoji、颜文字依次排列；云候选和 AI 候选也开启时，附加项会顺移。专门搜索表情可使用 E、M 模式。

#### 默认中英文

决定启动输入法或从其他输入法切回水杉输入法时，默认进入中文还是英文状态。

#### 中英文状态

- **按应用记忆**：每个应用分别记住中文或英文状态。例如可以让编辑器保持英文、聊天窗口保持中文。
- **全局统一**：所有应用共用同一个中英文状态，在一个应用里切换后，其他应用也跟着变化。

#### 简繁输入

选择“简体”时输出简体字，选择“繁体”时将候选结果转换为繁体字。

#### 云候选

**这一项出厂默认是开启的**，也是唯一一个不需要填任何密钥、装完就在联网的功能，所以单独说明：开启状态下，正在输入的拼音串会通过 HTTPS 发往谷歌云候选接口（`inputtools.google.com`）取一条候选。发出去的只有拼音串本身，不包含已上屏的文本、词库内容、调频数据或任何设置。云端返回的内容如果不在当前本地候选中，会插入第一页第 2 项。网络不可用时，本地输入不受影响。

不希望任何输入内容离开本机的话，在这里关掉它，或把 `%LOCALAPPDATA%\metasequoiaime\config.toml` 的 `[general]` 段改成 `cloud_candidates = false`；首次安装时也可以在“联网功能”页取消勾选。完整的联网清单见 [PRIVACY.md](https://github.com/metasequoiaime/msime-windows/blob/develop/PRIVACY.md)。

#### 整句候选

输入多个拼音音节时提供整句候选，由本机的语言模型生成，不联网。可以分别开关“Trigram 模型整句”“Unigram 模型整句”“神经网络模型整句（效果优先）”和“神经网络模型整句（速度优先）”：效果优先会结合已上屏的前文，从最多 12 个备选句中选择，处理时间较长；速度优先使用轻量模型。两种神经网络模式可以同时开启，各自给出结果。

- **去重后补充次选**：某个模型的首选与已有候选重复时，改为显示该模型排名最高的下一条不同结果。
- **显示整句来源标签**：在整句候选后显示〔Trigram〕〔Unigram〕〔神经D〕〔神经K〕等来源标签，默认关闭。

#### 拼音方案调频

调频会根据实际选词记录改变候选顺序。

- **调频方式**：“关闭”不调整顺序；“一次置顶”把触发调频的候选移到首位；“折半调频”把候选移到当前名次与首位之间；“线性调频”按固定步数向前；“一次置前”会让前五名中的候选前移一位，排在第五名之后的候选则直接提到第五名。
- **触发频次（第几次上屏触发）**：同一候选累计选中多少次后才调整一次，可选 `1`～`6`。数值越大，排序变化越稳。
- **线性调频步长**：使用“线性调频”时，每次向前移动多少位，可选 `1`～`6`；其他调频方式不会使用这个数值。

### 辅助码

辅助码是在完整拼音后追加的形码，可以把同音候选缩小到更容易挑选的范围。全拼和双拼分别有独立的开关、方案和显示设置。

#### 双拼辅助码

- **双拼辅助码**：控制双拼输入时是否识别辅助码。
- **双拼辅助码方案**：可选蓝天小雨点、自然码、首右 2.0、首右 Plus、小鹤和拼音加加，也可以使用下文的自定义辅助码。
- **在候选窗口中显示双拼辅助码**：开启后，候选文字旁会显示对应形码，便于记忆和核对。

#### 全拼辅助码

- **全拼辅助码**：控制全拼输入时是否识别辅助码。
- **全拼辅助码方案**：可选蓝天小雨点、自然码、首右 2.0、首右 Plus、小鹤和拼音加加，也可以使用下文的自定义辅助码。
- **在候选窗口中显示全拼辅助码**：开启后，在全拼候选文字旁显示对应形码。

#### 自定义辅助码

把 UTF-8 编码的 `.txt` 辅助码文件放进数据目录下的 `helpcodes\custom` 文件夹，点击“刷新方案”后即可在上方方案中选择；页面提供“打开目录”入口。每行写作 `字=辅助码`；方案名默认取文件名，也可以在文件开头用 `# name: 中文名` 和 `# name_en: English name` 注释指定。修改正在使用的方案文件后，需要切换一次方案或重启输入法才会生效。

#### 辅助码怎么输入

辅助码只有在前面的全拼或双拼编码已经完整时才会生效。如果拼音还没有输完整，末尾字母仍按普通拼音处理。

单码辅助主要调整顺序，不会丢掉其他候选：单字匹配该字的任意一个形码，词组匹配首字或末字的首个形码。在双拼中，小写单码优先排列第一位匹配的候选，大写单码优先排列第二位匹配的候选；对单字，两个位置是该字的两个形码，对词组则是首字和末字的首个形码。双码辅助会严格筛选：单字分别匹配两个形码，词组分别匹配首字和末字的首个形码。

以自然码中辅助码为 `ek` 的“阿”为例：

```text
全拼单码：aE
全拼双码：aEK
双拼单码：aae 或 aaK
双拼双码：aaeK、aaKe 或 aaKE
```

全拼追加的辅助码需要使用大写字母。双拼单码中，小写表示第一辅助码优先，大写表示第二辅助码优先。例如“阿”的辅助码为 `ek`：`aae` 优先匹配第一码 `e`，`aaK` 优先匹配第二码 `k`。

双拼双码辅助的大小写规则如下：

| 第一码 | 第二码 | 结果                 |
| ------ | ------ | -------------------- |
| 小写   | 小写   | 不触发双码辅助       |
| 小写   | 大写   | 触发，按正常顺序匹配 |
| 大写   | 小写   | 触发，按反转顺序匹配 |
| 大写   | 大写   | 触发，按反转顺序匹配 |

当第一码为大写时，第二码无论大小写都会触发双码辅助，输入顺序按“第二辅助码 → 第一辅助码”解释。因此 `Ke` 和 `KE` 都可以反向匹配实际辅助码 `ek`。

词组的用法相同。例如：

```text
全拼：ayiE / ayiEN
双拼：aayie / aayiN / aayieN / aayiNe / aayiNE
```

### 词库

#### 查询和维护词条

顶部可以切换全拼词库、五笔词库和英文词库。

- **全拼词库**：输入完整拼音查询，例如 `nihao`。新增词条时填写拼音、词条和权重，拼音可以用 `'` 分隔音节，例如 `ni'hao`。
- **五笔词库**：按五笔编码查询或新增词条。
- **英文词库**：按英文前缀查询。新增或编辑时填写检索用的单词、候选窗中的显示内容和权重。

查询结果每页显示 100 条，可用“上一页”“下一页”翻看。结果列表中的“编辑”和“删除”可以修改或移除用户词条；权重越高，通常越靠前。

#### 批量导入

顶部的“批量导入”支持全拼、五笔和英文词库。请选择 **UTF-8** 纯文本（`.txt`），可带 BOM；带 BOM 的 UTF-16 和 GBK 编码的文件也能识别；换行用 LF 或 CRLF 都可以。空行会被忽略；全拼和五笔词库还会跳过以 `#` 开头的注释行，英文词库不支持注释行，请不要在英文导入文件中写注释。**文件不要添加表头**；下面代码块只包含数据行，列之间为真正的 Tab。

列与列之间**只能使用 Tab**（`\t`），不能用空格、逗号或分号。词语里可以包含空格。已存在的词条会跳过，不会覆盖原有权重。

目前**不能直接导入**搜狗细胞词库（`.scel`）或搜狗导出的 `词语,拼音` 逗号分隔文本。请先转成下面的水杉格式再导入。如果需要让 AI 帮忙转换，把本节规范连同原始文件一起发给它即可。

Rime 的词库可以直接导入：全拼词库接受 `userdb.txt` 和 `.dict.yaml`，五笔词库接受 `.dict.yaml`，选择文件时可选 `.yaml` / `.yml`。文件开头的 YAML 段落和注释会被跳过，`userdb.txt` 第三列的 `c=…` 统计信息不作为权重，按默认权重导入。

##### 全拼词库

每行两列或三列，顺序固定为 **词语、全拼、权重**：

```text
你好	ni'hao	10
西安	xi'an	10
水杉输入法	shui'shan'shu'ru'fa	1
```

- 全拼必须是拼音表中的**完整音节**，不能用简拼。
- 推荐用 `'` 手动分音节，例如 `ni'hao`、`xi'an`。不写 `'` 时（包括 Rime 词库中用空格分隔的 `ni hao`），空格会被去掉，输入法按完整音节和词语字数自动切分，例如 `西安` 的全拼写 `xian` 时会按两个字切成 `xi'an`；但像 `fangan` 这样按字数仍有多种切法（`fang'an` 或 `fan'gan`）的拼音，请手动写 `'`。
- 音节数量必须与词语的字数一致。
- 权重必须是非负整数，可以省略，省略时为 `10000`。

##### 五笔词库

每行两列或三列，顺序为 **词语、五笔编码、权重**：

```text
你好	wbgq	10
```

编码只能是英文字母；导入时会转成小写。权重同样必须是非负整数，可以省略，省略时为 `30`。

##### 英文词库

每行两列或三列，顺序为 **单词、显示内容、权重**：

```text
meta	meta	10000
github	GitHub	15000
```

单词只支持英文字母、连字符和撇号，导入后会转成小写；显示内容会出现在候选窗中，可以保留大小写。权重可以省略，以兼容旧版导出的两列文件；省略时权重为 `0`。

##### 纯汉字词组

“批量导入纯汉字词组”适合人名等只有汉字、没有现成编码的文本，全拼词库和五笔词库页各有一个入口。文件中每行放一个词组，不要写编码或权重。在全拼词库页导入时，输入法自动注音并加入全拼词库，权重为 `10000`；在五笔词库页导入时，按 86 五笔词组取码规则生成编码并加入五笔词库，权重为 `30`。

##### 给 AI 或脚本生成文件

请生成 UTF-8 文本，每行一条，列之间用真正的 Tab 字符分隔，不要用空格或逗号。全拼、五笔和英文都可以是两列或三列，建议写上权重。全拼列请尽量带 `'` 分音节，并保证音节数等于汉字数。不要输出搜狗的 `词语,拼音` 格式。

#### 导出词库

可以分别导出拼音、五笔和英文用户词库。导出文件与上面的导入格式相同，适合备份、迁移或整理后重新导入。快捷短语用户词库的导出入口在“实用功能 → 快捷短语”。

### 语音输入

Windows 语音输入使用配置好的网络服务。当前设置提供豆包、OpenAI、SiliconFlow 和 Groq 的识别配置，文本润色可以单独选择服务。请按所用服务填写接口、模型和凭据；账户需具有对应接口权限。

#### 启用语音输入

总开关。开启后，可以在输入法右键菜单中点击“语音输入”开始或停止录音。

#### 语音输入快捷键

- **RAlt（长按录音）**：按住右 `Alt` 开始，松开后停止并识别。
- **Ctrl + Win（长按录音）**：先按住 `Ctrl`，再按 `Win` 开始；松开后停止。
- **RCtrl + RAlt（长按录音）**：先按住右 `Ctrl`，再按右 `Alt` 开始；松开后停止。
- **长按快捷键 + Space（锁定录音）**：录音时按空格锁定，随后松开长按键也不会停止。
- **Ctrl + F9（开始 / 停止录音）**：按一次开始，再按一次停止并识别；也可以用它结束已经锁定的录音。

录音过程中按 `Esc` 会取消本次录音，不提交识别结果。组合快捷键请按“先修饰键、后触发键”的顺序操作。

#### ASR API

- **服务提供商**：选择 `doubao`、`openai`、`siliconflow` 或 `groq`。豆包使用流式识别，其余使用语音转写接口。
- **API Token**：填写所选提供商的访问令牌，各提供商分别保存。请勿分享包含凭据的配置文件或截图。
- **接口地址与模型**：使用所选提供商的对应值，不能拿其他提供商的 Token 代替。
- **豆包鉴权方式**：“新版控制台 API Key”只需填写 API Key；“旧版控制台 App ID”需要填写 App ID 和 Access Token。

豆包另有“流式接口”选项：整句流式边录边传、说完返回整句，准确率更高；双向流式返回增量结果，刷新更频繁；选择后会同步写入接口地址。还可以设置数字格式化、标点预测、语义顺滑和热词表 ID；热词表需先在豆包语音自学习平台创建。语义顺滑与文本润色同时开启时，可能产生二次改写。

#### 文本润色 API

开启后，语音识别结果会发送给单独配置的文本服务整理，然后上屏。如果只需要原始识别结果，可以关闭此项。

- **服务提供商**：可选 `siliconflow`、`openai`、`deepseek` 或 `groq`。
- **API Token**：填写可调用所选文本模型的 Token，润色配置与识别配置独立。
- **接口地址与模型**：填写所选文本服务的聊天补全接口和模型。润色会发送转写文本，关闭后直接使用识别结果。

润色预设包括精炼整理、忠实校对、中翻英、口语整理，并提供三套自定义提示词。按希望上屏的文本形式选择；翻译类预设会改变输出语言。

#### 基础设置

- **识别语言**：可选简体中文、English 或自动。语言明确时直接选择对应项，通常比自动判断更稳定。
- **识别结果上屏方式**：`TSF 上屏` 走输入法框架提交文本，通常优先使用；`SendInput` 模拟键盘输入；`Ctrl+V 上屏` 通过剪贴板粘贴。遇到某个应用无法正常接收结果时，可以尝试另外两种方式。
- **录音提示音**（位于页面上方）：总开关下可以分别设置开始录音和结束录音时是否播放提示音。

豆包流式识别可以启用“流式 inline 预编辑”，将已识别文字直接显示在输入框中，松开录音键后上屏；仅 TSF 上屏方式生效。“录音时静音其他声音”会暂时关闭其他应用的播放声音，并在录音结束后恢复。

### 实用功能

下面的字母快捷模式在中文状态、没有正在输入的组词时进入，并由各自开关控制。

#### 剪贴板管理

开启后，复制过的文本显示在表情面板的剪贴板分页中；只记录文本。关闭功能会立即清空记录，复制敏感内容前可先关闭。

#### 快捷短语（K 模式）

开启后，在中文状态下按 `Shift + K` 进入快捷短语模式，再输入编码即可调用短语。编码只能包含英文字母，触发键 `K` 本身不属于编码。

“快捷短语混入候选”默认关闭。开启后，在全拼或双拼下输入的编码与快捷短语的编码完全一致时，快捷短语直接出现在候选首位（固定位置的候选之后），不用按 `Shift + K`；五笔不支持。“快捷短语参与调频”默认开启：经常越过快捷短语选别的候选时，它会往后退，最多退到首页最后一位；关闭后快捷短语始终在首位。

搜索框按编码前缀查询，留空可以查看全部。点击“新增短语”填写编码、短语和权重；已有短语可以编辑或删除。权重较高的短语会优先显示。

“批量导入”接受 UTF-8 纯文本，每行一条，不加表头，用真正的 Tab 分隔，格式与导出文件相同：

```text
mail	example@example.com	10
```

权重可以省略。编码只能是英文字母，重复条目会被跳过。下方的“导出快捷短语用户词库”用于备份用户新增的短语。

#### 日期与时间快捷输入（T 模式）

开启后，在中文状态下按 `Shift + T` 进入该模式：

- 输入 `rq`、`riqi` 或 `date`，选择当前日期。
- 输入 `sj`、`shijian` 或 `time`，选择当前时间。
- 输入 `xq`、`xingqi` 或 `week`，选择当前星期（中文与英文）。

#### Unicode 便捷录入（U 模式）

开启后，在中文状态下按 `Shift + U`，再输入 Unicode 十六进制码位，例如 `4e00` 或 `+1f600`。按空格上屏首选结果；需要选择其他候选时，使用 `Shift + 数字`。

#### Emoji（E 模式）与颜文字（M 模式）

在中文状态、没有正在输入的组词时，按 `Shift + E` 搜索 emoji，按 `Shift + M` 搜索颜文字。支持全拼、简拼、双拼或英文关键词，例如 emoji 的 `xiaolian` / `xl` / `laugh`、颜文字的 `haixiu` / `kiss`。按空格选择高亮结果，`Esc` 取消；可分别关闭这些入口。

#### 超级简拼（J 模式）

开启后，在中文状态下按 `Shift + J` 进入超级简拼：之后输入的每个字母都按简拼检索词库，而不会被切成完整音节。全拼例如 `nh` 得到「你好」，`an` 得到两字词而不是「安」。双拼会按当前方案把键转换成声母，因此小鹤 `u` / 自然码 `u` / 微软 `u` 对应 `sh`：`nu` 匹配 `n'sh`（你说），`ns` 匹配 `n's`，两者不会混在一起。空格上屏首选；数字选词。调频、置顶规则与全拼 / 双拼相同。

#### 临时英文（Y 模式）

开启后，在中文状态下按 `Shift + Y` 进入临时英文：之后输入的字母按英文处理，不会当作拼音。空格上屏当前输入；数字可选英文词库中的单词。上屏后自动回到中文输入。

#### 临时日语（R 模式）

开启后，在中文状态、没有正在输入的组词时按 `Shift + R`，再输入日语罗马字。空格选择首选，数字选择其他候选；上屏后回到中文。

### AI 辅助

#### 启用 AI 联想

开启后，全拼和双拼输入会异步请求所选 AI 服务。返回内容如果不与本地或云候选重复，会插入第一页第 3 项。请求需要网络，接口异常时不会影响本地候选。当前可选 DeepSeek、OpenAI、SiliconFlow 和 Groq，使用兼容 Chat Completions 的接口。

#### API 配置

- **服务提供商**：可选 `deepseek`、`openai`、`siliconflow` 或 `groq`。
- **模型**：填写所选服务实际支持的模型名称。若没有特殊需要，沿用安装版本给出的默认值。
- **API Token**：填写所选服务的 API Token，各提供商分别保存在本机配置中，不要公开配置文件或截图。
- **候选数量**：告诉模型最多生成多少条结果，范围为 `1`～`10`。当前输入法会采用返回结果中的第 1 条，因此这个数值主要用于约束接口输出。
- **接口地址**：填写所选服务的完整对话补全接口。例如 DeepSeek 使用 `https://api.deepseek.com/chat/completions`；更换提供商后一起核对模型、接口和 Token。

#### 自定义提示词

可以保存并切换三套自定义提示词。提示词用来规定模型怎样根据拼音、上下文和候选数量生成结果。修改时应保留“按拼音对应候选”和“只返回约定 JSON 结构”这类约束，否则可能出现候选读音不符或接口结果无法解析的问题。

### 悬浮工具栏

#### 在桌面显示悬浮工具栏

控制桌面悬浮工具栏是否显示。工具栏用于查看输入状态并快速打开常用功能，下方区域会预览当前效果。

#### 自动隐藏工具栏

默认关闭。开启后，工具栏在设定的延时（`1`～`60` 秒，默认 `5` 秒）内没有交互就会淡出；鼠标停在工具栏上时不会隐藏，切换中英文、全半角、标点等状态时重新显示。

#### 光标状态提示

在文字光标附近短暂显示输入法状态，可与悬浮工具栏同时开启，两项开关默认关闭：

- **切换输入法状态时提示**：切换输入模式、全半角或中英文标点时显示。
- **切换输入框时提示**：焦点移到另一个输入框时（包括同一窗口内和其他窗口中的），也提示当前中英文状态。
- **提示位置**：可选光标的左上方、正上方、右上方、左下方、正下方或右下方。

#### 工具栏外观

- **工具栏缩放**：可选 `75%`、`100%`、`125%`、`150%`。这是相对于 Windows DPI 的额外缩放，不会改变系统显示设置。
- **图标尺寸**：可选 `16`～`28` 像素，最终显示大小还会乘以上面的工具栏缩放比例。

#### 工具栏组件

中英文切换始终显示，不能取消。其余可按需勾选：全角 / 半角、中英文标点、简繁切换、表情与符号、屏幕键盘和设置。取消勾选只会隐藏工具栏入口，不会关闭对应功能。

### 统计

“启用输入统计”默认关闭。开启后只在本机记录每天、每小时各类字符（中文、英文字母、数字、标点和其他）的数量与活跃时长，不记录输入内容，也不联网；中文和英文模式都会记录。页面显示输入速度、近 12 个月的日历热力图、今日时段分布、字符分类和最近 30 天的按日明细。输入速度按可读字数（中文加英文）除以活跃分钟计算，数字和标点不计入，相邻上屏间隔不超过 10 秒计为活跃。

“自动清理”可选永久保留或保留最近 30、90、180、365 天，超期记录在跨天后首次写入统计时删除；“清空统计数据”会立即删除全部记录（包括今天），无法恢复。关闭开关后停止记录，已有数据继续保留。统计数据保存在数据目录的 `stats.db` 中，页面提供“打开数据目录”入口。

## 更新、备份与故障排查

更新前在“词库”中分别导出全拼、五笔和英文用户词库，并在“实用功能”导出快捷短语。导出词条不等于备份全部配置；本机配置位于 `%LOCALAPPDATA%\metasequoiaime\config.toml`，其中的 API Token 等服务凭据以明文保存，备份请自行保管；学到的词频和用户造词保存在同一目录的 `msime_user.db`。更新使用官网或 Release 提供的安装包覆盖安装，按对应发布说明操作，覆盖安装会保留用户词库、配置、皮肤和统计数据。卸载可从 Windows“已安装的应用”进入；卸载会删除数据目录中的用户词库、配置等数据，重要词条请先导出。

- **候选窗或设置页空白**：确认 Server 正在运行，检查 Microsoft Edge WebView2 Runtime 是否安装；参照安装版本的发布说明排查。
- **只有特定应用不能上屏**：先在记事本复现并对比，记录宿主程序及版本、是否以管理员身份运行、所用输入模式。
- **导入部分失败**：按返回的行号检查 Tab、列数、权重和拼音音节数；修正失败行后重新导入，已存在条目会跳过。
- **联网功能失败**：先关闭相应联网功能确认本地输入正常，再核对网络、服务地址、模型和凭据；AI 辅助、语音输入和候选词翻译的配置旁都有“测试配置”按钮。不要在公开反馈中粘贴 Token。

云候选会发送拼写，AI 联想会发送用于生成候选的拼写与上下文，在线翻译会发送候选，语音识别会发送音频，润色会发送转写文本，检查更新只在点击时请求版本信息。需要离线输入时，关闭这些联网选项；本地词库输入、整句候选和输入统计都在本机完成。

## 项目结构

Windows 版的全部一方源码都在 [msime-windows](https://github.com/metasequoiaime/msime-windows) 一个仓库里，一次 clone 就能构建完整产品：

- [windows/](https://github.com/metasequoiaime/msime-windows/tree/develop/windows)：TSF 文本服务 DLL，负责按键预判、焦点和与 Server 之间的管道协议。
- [server/](https://github.com/metasequoiaime/msime-windows/tree/develop/server)：常驻 Server，负责引擎调度、候选窗与工具栏的宿主、设置程序和词库管理。
- [engine/](https://github.com/metasequoiaime/msime-windows/tree/develop/engine)：输入引擎，包括输入会话、候选查询、辅助码和语音模块。源自已归档的 msime-engine，现在随 Windows 版一起开发。
- [ui/](https://github.com/metasequoiaime/msime-windows/tree/develop/ui)：自研原生 GUI 框架，Win32 窗口加 Direct2D / DirectWrite 渲染。
- [ui-html/](https://github.com/metasequoiaime/msime-windows/tree/develop/ui-html)：WebView2 界面资源，包括候选窗、悬浮工具栏、托盘菜单和设置页。
- [installer/](https://github.com/metasequoiaime/msime-windows/tree/develop/installer)：Inno Setup 安装器。

相关仓库：

- [msime](https://github.com/metasequoiaime/msime)：多平台主仓库，包含 macOS、iOS、Linux、Android 与 HarmonyOS 的前端，以及它们共用的 Rust 输入引擎。仓库里的 Windows 宿主仍在开发中，没有发布；目前发布的 Windows 版来自 msime-windows。
- [msime-dictionary](https://github.com/metasequoiaime/msime-dictionary)：词库源数据，包括基础词库、人工维护的词条与专业词库。
- [msime-cloud](https://github.com/metasequoiaime/msime-cloud)：云候选、AI 联想、翻译与语音识别的后端。目前发布的 Windows 版不经过它：云候选直接请求谷歌，AI 联想、翻译和语音识别直接请求你填写的服务商。
- [msime-skins](https://github.com/metasequoiaime/msime-skins)：候选窗皮肤。

msime-engine、msime-linux、MSIME-UI、MSIME-UiHtml、MSIME-Windows-Server、MSIME-Installer 等旧仓库已经归档，保留历史提交和已发布的 Release。

文档会随功能继续更新。如果发现说明和实际行为不一致，欢迎在 [GitHub Issues](https://github.com/metasequoiaime/msime-windows/issues) 中反馈。
