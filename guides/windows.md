# 水杉输入法文档

水杉输入法（Metasequoia IME）是一款面向 Windows 10、Windows 11 的开源中文输入法，采用纯 TSF 方案。目前支持全拼、双拼和 86 五笔，也提供辅助码、云候选、AI 联想、语音输入、手写输入和快捷短语等功能。

## 下载安装

请前往[官网下载页面](https://msime.app/download/)获取最新版本，并按对应版本的 GitHub Release 说明完成安装。不同版本的安装方式和功能可能会有变化，以发布说明为准。

![安装完成截图](https://msime.app/screenshots/install-finish.png)

安装完成后，请确认 Metasequoia IME Server 和 Metasequoia IME Watchdog 已经启动。按 `Win + Space` 切换到水杉输入法后即可开始使用。

### 安装后无法使用或设置窗口闪退

如果安装完成后无法正常切换到水杉输入法，或者打开设置窗口后立即退出，请先检查 Microsoft Visual C++ 运行库。水杉输入法的 Server 和设置程序均为 64 位程序，需要安装最新的 **Microsoft Visual C++ 2015–2022 Redistributable（x64）**。

请注意，64 位 Windows 可以同时安装 x86 和 x64 两套 Visual C++ 运行库。只安装或更新 `vc_redist.x86.exe` 不能满足水杉输入法的运行要求；即使“已安装的应用”中已经出现 Microsoft Visual C++ Redistributable，也要确认名称中包含 **x64**。

典型现象包括：

- 使用 `Win + Space` 切换后输入法没有响应；
- Metasequoia IME Server 启动后反复退出；
- 设置窗口打开后立即消失；
- Windows 事件查看器记录 `MetasequoiaImeServer.exe` 或 `MetasequoiaImeSettings.exe` 在 `MSVCP140.dll` 中以 `0xc0000005` 异常退出。

遇到上述情况时，请前往[微软官方下载页面](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170)，在最新支持版本中下载并安装 x64 架构的 `vc_redist.x64.exe`。如果安装程序提供“修复”选项，请执行修复；安装完成后建议重新启动 Windows，再运行水杉输入法。不要用 `vc_redist.x86.exe` 代替 x64 版本。

如果安装最新 x64 运行库并重启后仍无法使用，请在卸载水杉输入法之前运行诊断脚本并将生成的报告提交给开发者。卸载后安装文件和部分诊断信息会被清理，不利于继续定位问题。

## 设置窗口

下面按照设置窗口左侧功能区从上到下的顺序逐项说明。配置修改后会自动保存，一般不需要再点“应用”或“确定”。

### 外观

#### 候选窗口预览

同时显示横排和竖排候选窗的效果。更改字体、字号、颜色、主题或排列方式时，可以先在这里查看大致效果。

#### 候选窗样式

- **候选窗主字体**：候选窗优先使用的西文字体，主要影响拉丁字母、数字和标点。列表来自当前系统已经安装的字体。
- **候选窗中文补充字体**：用于显示汉字以及主字体缺少的字符。列表同样取自系统字体。
- **候选窗字号**：可选 `12`～`32` 像素。字号越大，候选窗占用的空间也越大。
- **候选文字颜色**：点击色块可以自定义候选文字颜色；点击“跟随主题”后，文字颜色会重新随深色、浅色主题自动变化。
- **每页候选项数量**：可选 `3`～`9` 项。这里只改变一页显示多少项，不会减少实际候选结果。

#### 主题模式

全局主题可选“深色”“浅色”或“跟随系统”。“跟随系统”会使用 Windows 当前的应用颜色模式。

#### 各界面主题

设置界面、候选窗口、悬浮工具栏、菜单、表情面板、屏幕键盘、手写识别板和语音输入弹出条都可以单独指定主题。每一项都有“跟随全局”“深色”和“浅色”三个选项。

“跟随全局”表示使用上面的“主题模式”；单独选择深色或浅色后，该界面不再随全局主题切换。

#### 候选项排列方式

“横向”会把候选项排在一行，“纵向”则逐行显示。两种样式只改变候选窗布局，不影响候选排序。

#### 行内预编辑

行内预编辑是光标所在应用中显示的未上屏输入串。

- **原始按键**：显示实际键入的字母。
- **拼音分词**：显示输入法切分后的拼音。
- **不显示**：应用内不显示预编辑串，候选窗仍可照常使用。

#### 候选窗预编辑

控制候选窗顶部是否显示输入串。“拼音分词”会显示切分后的拼音，“不显示”会隐藏这一行。它和“行内预编辑”相互独立，可以分别设置。

### 输入

#### 输入方案

- **全拼**：按完整拼音输入。
- **双拼**：用两个按键组合声母和韵母。选择后，下方的“双拼方案”才有实际作用。
- **五笔**：使用五笔字型输入。当前设置窗口提供 86 五笔。

#### 双拼方案

可选小鹤双拼、自然码双拼、首道双拼和微软双拼。切换方案会改变双拼键位映射，不会改动全拼和五笔设置。

#### 五笔方案

当前可选项为“86 五笔”。

#### 翻页方式

这里可以同时勾选多组按键：

- `-` / `=`：上一页 / 下一页。
- `,` / `.`：上一页 / 下一页。
- `Shift + Tab` / `Tab`：上一页 / 下一页。
- `Page Up` / `Page Down`：上一页 / 下一页。
- `↑` / `↓`：在候选项之间移动高亮位置。

取消某一项后，对应按键不再用于候选操作，适合避开自己常用软件中的按键习惯。

#### 以词定字

开启后，按 `[` 上屏当前高亮候选的第一个汉字，按 `]` 上屏最后一个汉字。遇到单字难找、但相关词组很容易输入时，这个功能会比较顺手。

#### 智能标点

在中文标点状态下，如果逗号、句点或冒号前面紧接着字母或数字，输入法会自动输出英文的 `,`、`.`、`:`。输入网址、版本号、时间或小数时，可以少切一次标点状态。

#### 成对标点自动补全

输入左侧括号、引号等成对符号时，自动补上右侧符号，并把光标放在两者中间。

#### 常用输入状态和中文标点

- 按 `Ctrl + .` 可以在中文标点和英文标点之间切换，也可以点击悬浮工具栏上的“中英文标点”。
- 按 `Ctrl + Shift + Space` 可以切换全角和半角字符。
- 在中文模式下按 `Ctrl + Shift + E`，可以进入或退出独立的英文候选输入模式。这个模式与下方的“中英混输”不同：中英混输是在拼音候选中补充英文，英文候选模式则专门按英文词库匹配当前字母串。
- 中文标点状态下，按反斜杠键 `\` 输入顿号 `、`。这是顿号对应的直接按键，不需要先打开符号面板。
- 其他常见对应关系包括：键盘左上角的反引号键输入间隔号 `·`，`Shift + 6` 输入省略号 `……`，`Shift + -` 输入破折号 `——`，`Shift + ,` / `Shift + .` 输入书名号 `《` / `》`。

已经有候选时，输入中文标点通常会先上屏当前高亮候选，再紧跟标点。如果只是想取消当前输入，请按 `Esc`。

#### 中英混输

开启后，在中文输入状态下也会根据字母串给出英文候选。预编辑串超过 4 个字符时会自动触发英文候选，适合在中文句子中穿插英文单词。

#### 默认中英文

决定启动输入法或从其他输入法切回水杉输入法时，默认进入中文还是英文状态。

#### 中英文状态

- **按应用记忆**：每个应用分别记住中文或英文状态。例如可以让编辑器保持英文、聊天窗口保持中文。
- **全局统一**：所有应用共用同一个中英文状态，在一个应用里切换后，其他应用也跟着变化。

#### 简繁输入

选择“简体”时输出简体字，选择“繁体”时将候选结果转换为繁体字。

#### 云候选

开启后会请求谷歌云候选接口。云端返回的内容如果不在当前本地候选中，会插入第一页第 2 项。此功能需要网络连接；网络不可用时，本地输入不受影响。

#### 拼音方案调频

调频会根据实际选词记录改变候选顺序。

- **调频方式**：“关闭”不调整顺序；“一次置顶”把触发调频的候选移到首位；“折半调频”把候选移到当前名次与首位之间；“线性调频”按固定步数向前；“一次置前”会让前五名中的候选前移一位，排在第五名之后的候选则直接提到第五名。
- **触发频次（第几次上屏触发）**：同一候选累计选中多少次后才调整一次，可选 `1`～`6`。数值越大，排序变化越稳。
- **线性调频步长**：使用“线性调频”时，每次向前移动多少位，可选 `1`～`6`；其他调频方式不会使用这个数值。

### 辅助码

辅助码是在完整拼音后追加的形码，可以把同音候选缩小到更容易挑选的范围。全拼和双拼分别有独立的开关、方案和显示设置。

#### 双拼辅助码

- **双拼辅助码**：控制双拼输入时是否识别辅助码。
- **双拼辅助码方案**：可选蓝天小雨点、自然码、首右 2.0、首右 Plus 和小鹤。
- **在候选窗口中显示双拼辅助码**：开启后，候选文字旁会显示对应形码，便于记忆和核对。

#### 全拼辅助码

- **全拼辅助码**：控制全拼输入时是否识别辅助码。
- **全拼辅助码方案**：可选蓝天小雨点、自然码、首右 2.0、首右 Plus 和小鹤。
- **在候选窗口中显示全拼辅助码**：开启后，在全拼候选文字旁显示对应形码。

#### 辅助码怎么输入

辅助码只有在前面的全拼或双拼编码已经完整时才会生效。如果拼音还没有输完整，末尾字母仍按普通拼音处理。

单码辅助主要调整顺序，不会丢掉其他候选：单字匹配该字的任意一个形码，词组匹配首字或末字的首个形码。在双拼中，小写单码优先排列第一位匹配的候选，大写单码优先排列第二位匹配的候选；对单字，两个位置是该字的两个形码，对词组则是首字和末字的首个形码。双码辅助会严格筛选：单字分别匹配两个形码，词组分别匹配首字和末字的首个形码。

以自然码中辅助码为 `ek` 的“阿”为例：

```text
全拼单码：aE
全拼双码：aEK
双拼单码：aae 或 aaK
双拼双码：aaeK、aaKe 或 aaKE
```

全拼追加的辅助码需要使用大写字母。双拼单码中，小写表示第一辅助码优先，大写表示第二辅助码优先。例如“阿”的辅助码为 `ek`：`aae` 优先匹配第一码 `e`，`aaK` 优先匹配第二码 `k`。

双拼双码辅助的大小写规则如下：

| 第一码 | 第二码 | 结果                 |
| ------ | ------ | -------------------- |
| 小写   | 小写   | 不触发双码辅助       |
| 小写   | 大写   | 触发，按正常顺序匹配 |
| 大写   | 小写   | 触发，按反转顺序匹配 |
| 大写   | 大写   | 触发，按反转顺序匹配 |

当第一码为大写时，第二码无论大小写都会触发双码辅助，输入顺序按“第二辅助码 → 第一辅助码”解释。因此 `Ke` 和 `KE` 都可以反向匹配实际辅助码 `ek`。

词组的用法相同。例如：

```text
全拼：ayiE / ayiEN
双拼：aayie / aayiN / aayieN / aayiNe / aayiNE
```

### 快捷键

#### 中英文切换

可以分别启用 `Shift`、`Ctrl` 和 `Ctrl + Alt + Space`。这些快捷键只负责水杉输入法内部的中英文切换。

`Ctrl + Space` 由 Windows 管理，不受这里的开关控制。如需修改，请进入 Windows“设置 → 时间和语言 → 输入 → 高级键盘设置 → 输入语言热键”，选中“中文（简体）输入法 - 输入法 / 非输入法切换”后更改按键顺序。不同 Windows 版本的文字可能略有不同；修改后未立即生效时，可以重新登录或重启电脑。

#### 候选操作

- `Space` 或 `1`～`9`：选择候选。
- `-` / `=`、`,` / `.`、`Shift + Tab` / `Tab`、`Page Up` / `Page Down`：候选翻页。是否生效由“输入 → 翻页方式”中的勾选项决定。
- `↑` / `↓`：移动候选项。
- `←` / `→`、`Backspace`：移动光标或修改输入串。
- `Enter`：提交原始输入；`Esc`：取消本次输入。

#### 全局快捷键

以下快捷键在输入法服务运行期间全局生效，主要用于维护和排查问题：

- `Ctrl + Shift + Alt + 1`～`8`：删除当前候选窗口中对应位置的候选项。
- `Ctrl + Shift + Alt + C`：清除输入法引擎缓存。
- `Ctrl + Shift + Alt + R`：重启输入法服务。
- `Ctrl + Shift + Alt + T`：立即退出输入法服务。退出后需要重新启动服务才能继续使用。

### 词库

#### 查询和维护词条

顶部可以切换全拼词库、五笔词库和英文词库。

- **全拼词库**：输入完整拼音查询，例如 `nihao`。新增词条时填写拼音、词条和权重，拼音可以用 `'` 分隔音节，例如 `ni'hao`。
- **五笔词库**：按五笔编码查询或新增词条。
- **英文词库**：按英文前缀查询。新增或编辑时填写检索用的单词、候选窗中的显示内容和权重。

查询最多显示 100 条结果。结果列表中的“编辑”和“删除”可以修改或移除用户词条；权重越高，通常越靠前。

#### 批量导入

顶部的“批量导入”支持全拼、五笔和英文词库。请选择 **UTF-8** 纯文本（`.txt`），可带 BOM；换行用 LF 或 CRLF 都可以。空行会被忽略。

列与列之间**只能使用 Tab**（`\t`），不能用空格、逗号或分号。词语里可以包含空格。已存在的词条会跳过，不会覆盖原有权重。

目前**不能直接导入**搜狗细胞词库（`.scel`）或搜狗导出的 `词语,拼音` 逗号分隔文本。请先转成下面的水杉格式再导入。如果需要让 AI 帮忙转换，把本节规范连同原始文件一起发给它即可。

##### 全拼词库

每行三条，顺序固定为 **词语、全拼、权重**：

```text
词语	全拼	权重
你好	ni'hao	10
西安	xi'an	10
水杉输入法	shui'shan'shu'ru'fa	1
```

- 全拼必须是拼音表中的**完整音节**，不能用简拼。
- 推荐用 `'` 手动分音节，例如 `ni'hao`、`xi'an`。没有 `'` 时，输入法会按完整音节自动切分；像 `西安` 这种容易切成 `xian` 的词，请写成 `xi'an`。
- 音节数量必须与词语的字数一致。
- 权重必须是非负整数，**不能省略**。

##### 五笔词库

每行三条，顺序为 **词语、五笔编码、权重**：

```text
词语	五笔编码	权重
你好	wbgq	10
```

编码只能是英文字母；导入时会转成小写。权重同样必须是非负整数，不能省略。

##### 英文词库

每行两条或三条，顺序为 **单词、显示内容、权重**：

```text
单词	显示内容	权重
meta	meta	10000
github	GitHub	15000
```

单词只支持英文字母、连字符和撇号，导入后会转成小写；显示内容会出现在候选窗中，可以保留大小写。权重可以省略，以兼容旧版导出的两列文件；省略时权重为 `0`。

##### 纯汉字词组

“批量导入纯汉字词组”适合人名等只有汉字、没有现成拼音编码的文本。文件中每行放一个词组，不要写拼音或权重；输入法会自动注音并加入全拼词库，默认权重为 `10000`。

##### 给 AI 或脚本生成文件

请生成 UTF-8 文本，每行一条，列之间用真正的 Tab 字符分隔，不要用空格或逗号。全拼和五笔必须正好三列；英文可以两列或三列。全拼列请尽量带 `'` 分音节，并保证音节数等于汉字数。不要输出搜狗的 `词语,拼音` 格式。

#### 导出词库

可以分别导出拼音、五笔和英文用户词库。导出文件与上面的导入格式相同，适合备份、迁移或整理后重新导入。快捷短语用户词库的导出入口在“实用功能 → 快捷短语”。

### 皮肤

当前提供 Fluent 默认皮肤。页面中的开关表示它是当前启用的皮肤，不能在这里关闭；“预览浅色 / 预览深色”只切换预览效果，不会改动“外观”中的实际主题。下方依次展示横排候选窗、竖排候选窗和悬浮工具栏效果。

### 语音输入

语音输入需要网络服务，目前只支持硅基流动（SiliconFlow）。使用前请在硅基流动申请自己的 API Token；其他厂商即使接口格式相似，目前也不能保证正常识别或润色。

#### 启用语音输入

总开关。开启后，可以在输入法右键菜单中点击“语音输入”开始或停止录音。

#### 语音输入快捷键

- **RAlt（长按录音）**：按住右 `Alt` 开始，松开后停止并识别。
- **Ctrl + Win（长按录音）**：先按住 `Ctrl`，再按 `Win` 开始；松开后停止。
- **RCtrl + RAlt（长按录音）**：先按住右 `Ctrl`，再按右 `Alt` 开始；松开后停止。
- **长按快捷键 + Space（锁定录音）**：录音时按空格锁定，随后松开长按键也不会停止。
- **Ctrl + F9（开始 / 停止录音）**：按一次开始，再按一次停止并识别；也可以用它结束已经锁定的录音。

录音过程中按 `Esc` 会取消本次录音，不提交识别结果。组合快捷键请按“先修饰键、后触发键”的顺序操作。

#### ASR API

- **服务提供商**：当前固定为 `siliconflow`，不需要改成其他厂商名称。
- **API Token**：填写在硅基流动申请的访问令牌。Token 会写入本机配置，请勿分享配置文件或相关截图。
- **接口地址**：硅基流动的语音转文字接口，默认是 `https://api.siliconflow.cn/v1/audio/transcriptions`。除非硅基流动调整接口地址，否则保持默认即可。

#### 文本润色 API

开启后，语音识别结果会再交给硅基流动的文本接口整理，然后上屏。如果只需要原始识别结果，可以关闭此项。

- **服务提供商**：当前同样固定为 `siliconflow`。
- **API Token**：填写可调用硅基流动文本模型的 Token，可以与上面的 ASR Token 相同，但仍需确保账户有相应接口权限。
- **接口地址**：默认是 `https://api.siliconflow.cn/v1/chat/completions`，一般保持默认。

#### 基础设置

- **识别语言**：可选简体中文、English 或自动。语言明确时直接选择对应项，通常比自动判断更稳定。
- **识别结果上屏方式**：`TSF 上屏` 走输入法框架提交文本，通常优先使用；`SendInput` 模拟键盘输入；`Ctrl+V 上屏` 通过剪贴板粘贴。遇到某个应用无法正常接收结果时，可以尝试另外两种方式。
- **开始和停止录音时播放提示音**：控制录音开始、结束时是否发出声音提示。

### 屏幕键盘

点击“打开”启动屏幕键盘，可以用鼠标或触控输入文字和快捷按键。下方图片用于预览界面；屏幕键盘的深浅色在“外观 → 屏幕键盘主题”中设置。

### 手写识别板

点击“打开”启动手写识别板。用鼠标或触控书写后，识别结果会以候选汉字显示；点击候选可将其复制到剪贴板，再粘贴到需要的位置。下方是界面预览；深浅色在“外观 → 手写识别板主题”中设置。若没有识别结果，请确认 Windows 已安装中文手写包。

### 实用功能

#### 快捷短语（K 模式）

开启后，在中文状态下按 `Shift + K` 进入快捷短语模式，再输入编码即可调用短语。编码只能包含英文字母，触发键 `K` 本身不属于编码。

搜索框按编码前缀查询，留空可以查看全部。点击“新增短语”填写编码、短语和权重；已有短语可以编辑或删除。权重较高的短语会优先显示。

“批量导入”接受 UTF-8 纯文本，每行一条，格式与导出文件相同：

```text
编码	短语	权重
mail	example@example.com	10
```

权重可以省略。编码只能是英文字母，重复条目会被跳过。下方的“导出快捷短语用户词库”用于备份用户新增的短语。

#### 日期与时间快捷输入（T 模式）

开启后，在中文状态下按 `Shift + T` 进入该模式：

- 输入 `rq`、`riqi` 或 `date`，选择当前日期。
- 输入 `sj`、`shijian` 或 `time`，选择当前时间。
- 输入 `xq`、`xingqi` 或 `week`，选择当前星期（中文与英文）。

#### Unicode 便捷录入（U 模式）

开启后，在中文状态下按 `Shift + U`，再输入 Unicode 十六进制码位，例如 `4e00` 或 `+1f600`。按空格上屏首选结果；需要选择其他候选时，使用 `Shift + 数字`。

#### 超级简拼（J 模式）

开启后，在中文状态下按 `Shift + J` 进入超级简拼：之后输入的每个字母都按简拼检索词库，而不会被切成完整音节。全拼例如 `nh` 得到「你好」，`an` 得到两字词而不是「安」。双拼会按当前方案把键转换成声母，因此小鹤 `u` / 自然码 `u` / 微软 `u` 对应 `sh`，手心 `e` 对应 `sh`：`nu` 匹配 `n'sh`（你说），`ns` 匹配 `n's`，两者不会混在一起。空格上屏首选；数字选词。调频、置顶规则与全拼 / 双拼相同。

#### 临时英文（Y 模式）

开启后，在中文状态下按 `Shift + Y` 进入临时英文：之后输入的字母按英文处理，不会当作拼音。空格上屏当前输入；数字可选英文词库中的单词。上屏后自动回到中文输入。

### AI 辅助

#### 启用 AI 联想

开启后，全拼和双拼输入会异步请求 DeepSeek。返回内容如果不与本地或云候选重复，会插入第一页第 3 项。请求需要网络，接口异常时不会影响本地候选。目前只支持 DeepSeek，不能直接换成其他兼容 Chat Completions 格式的服务。

#### API 配置

- **服务提供商**：当前固定为 `deepseek`，保持默认即可。
- **模型**：填写 DeepSeek API 实际支持的模型名称。若没有特殊需要，沿用安装版本给出的默认值。
- **API Token**：填写在 DeepSeek 申请的 API Token。Token 保存在本机配置中，不要公开配置文件或截图。
- **候选数量**：告诉模型最多生成多少条结果，范围为 `1`～`10`。当前输入法会采用返回结果中的第 1 条，因此这个数值主要用于约束接口输出。
- **接口地址**：DeepSeek 的对话补全接口，默认是 `https://api.deepseek.com/chat/completions`。目前不要填写其他厂商的接口地址。

#### 自定义提示词

提示词用来规定模型怎样根据拼音、上下文和候选数量生成结果。修改时应保留“按拼音对应候选”和“只返回约定 JSON 结构”这类约束，否则可能出现候选读音不符或接口结果无法解析的问题。

### 悬浮工具栏

#### 在桌面显示悬浮工具栏

控制桌面悬浮工具栏是否显示。工具栏用于查看输入状态并快速打开常用功能，下方区域会预览当前效果。

#### 工具栏外观

- **工具栏缩放**：可选 `75%`、`100%`、`125%`、`150%`。这是相对于 Windows DPI 的额外缩放，不会改变系统显示设置。
- **图标尺寸**：可选 `16`～`28` 像素，最终显示大小还会乘以上面的工具栏缩放比例。

#### 工具栏组件

中英文切换始终显示，不能取消。其余可按需勾选：全角 / 半角、中英文标点、简繁切换、表情与符号、屏幕键盘和设置。取消勾选只会隐藏工具栏入口，不会关闭对应功能。
