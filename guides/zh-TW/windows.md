# 水杉輸入法文件

水杉輸入法（Metasequoia IME）是一款面向 Windows 10、Windows 11 的開源中文輸入法，採用純 TSF 方案。目前支援全拼、雙拼、86 五筆和日語羅馬音輸入，也提供輔助碼、雲端候選字、AI 聯想、語音輸入、手寫輸入和快捷片語等功能。

本頁採用臺灣繁體中文用語；引號內的應用程式選項、程式碼、檔名與範例保留原文，方便對照實際介面。

本文按 2026-10-01 核對的 Windows 原始碼（v0.9.3）整理。安裝套件可能早於原始碼，找不到某個選項時請先檢視該版本的發布說明。

## 下載安裝

請前往[官網下載頁面](https://msime.app/zh-TW/download/)獲取最新版本，並按對應版本的 GitHub Release 說明完成安裝。不同版本的安裝方式和功能可能會有變化，以發布說明為準。

安裝程式會先檢查 Microsoft Edge WebView2 Runtime 和 Visual C++ 2015–2022 x64 執行階段，缺少時給出說明和下載入口。精靈中可以選擇資料目錄，用來存放詞庫、配置和佈景主題，預設是 `%LOCALAPPDATA%\metasequoiaime`，也可以放到其他磁碟；升級安裝時改到新位置會遷移現有資料。首次安裝還會顯示“联网功能”頁，詢問是否啟用雲端候選字，詳見下文“雲端候選字”。本文後面的路徑都以預設資料目錄為例，改過位置時請換成自己的資料目錄。

安裝完成後，安裝程式會啟動 Server（`MetasequoiaImeServer.exe`）和 Watchdog（`MetasequoiaImeWatchdog.exe`），可以在工作管理員中確認。Watchdog 會在登入時自動執行並拉起 Server，Server 意外退出後也會由它重新啟動。按 `Win + Space` 切換到水杉輸入法後即可開始使用。

### 安裝後無法使用或設定視窗閃退

如果安裝完成後無法正常切換到水杉輸入法，或者開啟設定視窗後立即退出，請先檢查 Microsoft Visual C++ 執行階段。水杉輸入法的 Server 和設定程式均為 64 位元程式，需要安裝最新的 **Microsoft Visual C++ 2015–2022 Redistributable（x64）**。

請注意，64 位元 Windows 可以同時安裝 x86 和 x64 兩套 Visual C++ 執行階段。只安裝或更新 `vc_redist.x86.exe` 不能滿足水杉輸入法的執行要求；即使“已安装的应用”中已經出現 Microsoft Visual C++ Redistributable，也要確認名稱中包含 **x64**。

典型現象包括：

- 使用 `Win + Space` 切換後輸入法沒有響應；
- Metasequoia IME Server 啟動後反覆退出；
- 設定視窗開啟後立即消失；
- Windows 事件檢視器記錄 `MetasequoiaImeServer.exe` 或 `MetasequoiaImeSettings.exe` 在 `MSVCP140.dll` 中以 `0xc0000005` 異常退出。

遇到上述情況時，請直接下載並安裝微軟官方的 [`vc_redist.x64.exe`](https://aka.ms/vc14/vc_redist.x64.exe)。如果安裝程式提供“修复”選項，請執行修復；安裝完成後建議重新啟動 Windows，再執行水杉輸入法。不要用 `vc_redist.x86.exe` 代替 x64 版本。

如果安裝最新 x64 執行階段並重啟後仍無法使用，請先保留錯誤提示、事件檢視器記錄和重現步驟，再按本文“反馈”一節提交問題。不要先解除安裝清理，以免丟失定位所需的資訊。

## 開始輸入

在記事本等文字框中切換到水杉，確認處於中文狀態和全拼方案，輸入 `nihao`，按空格選擇反白候選；也可按候選前的數字選擇。`Esc` 取消，`Enter` 提交原始字母串。透過輸入法右鍵選單或懸浮工具列的設定入口調整方案。

## 設定視窗

下面按照設定視窗左側功能區從上到下的順序逐項說明。配置修改後會自動儲存，一般不需要再點“应用”或“确定”。

### 外觀

#### 候選字視窗預覽

同時顯示橫排和直排候選字視窗的效果。更改字型、字級、顏色、主題或排列方式時，可以先在這裡檢視大致效果。

#### 介面渲染與游標跟隨

“界面渲染”可選 Direct2D（原生）或 WebView2，用於候選字視窗、懸浮工具列和系統匣選單。更改後需重啟輸入法程序才會生效，可以直接點選下方“重启输入法进程”一欄的“重启”。設定頁仍需要 WebView2 Runtime；表情、手寫和螢幕小鍵盤面板是原生視窗，不依賴它。

“设置窗口后台驻留”決定關閉設定視窗後程序保留多久，可選“关闭后立即退出”、1 分鐘到 1 小時或“一直驻留”。駐留期間再次開啟無需等待載入，但會繼續佔用記憶體。

“候选窗口跟随光标”關閉後，候選字視窗保持本次出現時的初始位置，直到視窗消失。

#### 固定候選徽標

開啟後，為手動固定位置的候選顯示角標，便於辨認。樣式可選迴紋針、圖釘或圓點。

#### 候選字視窗樣式

- **候選字視窗主字型**：候選字視窗優先使用的西文字型，主要影響拉丁字母、數字和標點。列表來自目前系統已經安裝的字型。
- **候選字視窗補充字型**：主字型缺少的字元（例如漢字）按這裡的順序依次回落，最後使用系統字型。可以點選“+”新增多個字型，列表同樣取自系統字型。
- **候選字視窗字級**：可選 `12`～`32` 像素。字級越大，候選字視窗佔用的空間也越大。
- **候選字視窗預編輯字級**：單獨調整候選字視窗頂部輸入字串的大小，可選 `12`～`32` 像素。
- **候選文字顏色**：點選色塊可以自訂候選文字顏色；點選“跟随主题”後，文字顏色會重新隨深色、淺色主題自動變化。
- **每頁候選項數量**：可選 `3`～`9` 項。這裡只改變一頁顯示多少項，不會減少實際候選結果。

#### 主題模式

全域主題可選“深色”“浅色”或“跟随系统”。“跟随系统”會使用 Windows 目前的應用顏色模式。

#### 各介面主題

設定介面、候選字視窗、懸浮工具列、選單、表情面板、螢幕小鍵盤、手寫辨識板和語音輸入彈出條都可以單獨指定主題。每一項都有“跟随全局”“深色”和“浅色”三個選項。

“跟随全局”表示使用上面的“主题模式”；單獨選擇深色或淺色後，該介面不再隨全域主題切換。

#### 候選項排列方式

“横向”會把候選項排在一行，“纵向”則逐行顯示。兩種樣式只改變候選字視窗配置，不影響候選排序。

#### 行內預編輯

行內預編輯是游標所在應用中顯示的尚未送出的輸入字串。

- **原始按鍵**：顯示實際鍵入的字母。
- **拼音分詞**：顯示輸入法切分後的拼音。
- **不顯示**：應用內不顯示預編輯串，候選字視窗仍可照常使用。

#### 候選字視窗預編輯

控制候選字視窗頂部是否顯示輸入字串。“拼音分词”會顯示切分後的拼音，“不显示”會隱藏這一行。它和“行内预编辑”相互獨立，可以分別設定。

### 輸入

#### 輸入模式與日語

“输入模式”可選中文或日文。中文下再選擇全拼、雙拼或五筆；日文使用羅馬音輸入，候選包含平假名、片假名和日語詞庫結果，日文下 `-` 用來輸入長音符 `ー`，`-` / `=` 都不再用於翻頁，請改用其他翻頁鍵。切回中文時保留原有中文方案。只需臨時輸入日語時，可以使用“实用功能”中的 R 模式。

#### 輸入方案

- **全拼**：按完整拼音輸入。
- **雙拼**：用兩個按鍵組合聲母和韻母。選擇後，下方的“双拼方案”才有實際作用。
- **五筆**：使用五筆字型輸入。目前設定視窗提供 86 五筆。

#### 雙拼方案

可選小鶴雙拼、自然碼雙拼、首道雙拼、微軟雙拼、搜狗雙拼、紫光雙拼、智能ABC、國標雙拼和拼音加加。切換方案會改變雙拼鍵位對映，不會改動全拼和五筆設定。

#### 自訂雙拼

把 UTF-8 編碼的 `.toml` 雙拼方案檔案放進資料目錄下的 `shuangpin\custom` 資料夾，點選“刷新方案”後即可在“双拼方案”中選擇；頁面提供“打开目录”入口。檔案裡用 `zero_initial_rule` 選擇零聲母規則，在 `[initials]` 和 `[finals]` 中寫聲母、韻母對應的按鍵，完整寫法見[示例檔案](https://github.com/metasequoiaime/msime-windows/blob/develop/docs/custom-shuangpin.example.toml)。有錯誤的方案顯示為灰色，滑鼠懸停可檢視原因。修改正在使用的方案檔案後，需要切換一次方案或重啟輸入法才會生效。

#### 五筆方案

目前可選項為“86 五笔”。四碼只有唯一候選時自動送出文字；四碼之後繼續輸入，前一個字會自動送出（頂字）。

- **拼音混輸**：同一串字母同時查五筆碼表和全拼，五筆候選在前，拼音候選在後。
- **z 鍵通配**：開啟後 `z` 可匹配碼表中該位置的任意字母（含首位），常用於首碼不確定時起頭。

#### 翻頁方式

這裡可以同時勾選多組按鍵：

- `-` / `=`：上一頁 / 下一頁。
- `,` / `.`：上一頁 / 下一頁。
- `[` / `]`：上一頁 / 下一頁。
- `Shift + Tab` / `Tab`：上一頁 / 下一頁。
- `Page Up` / `Page Down`：上一頁 / 下一頁。
- `↑` / `↓`：在候選項之間移動反白位置。
- 滑鼠滾輪：捲動候選字視窗翻頁。需要開啟 Windows 設定中的“当我悬停在非活动窗口上方时滚动它们”，否則滾輪不會傳到候選字視窗。

取消某一項後，對應按鍵不再用於候選操作，適合避開自己常用軟體中的按鍵習慣。`[` / `]` 和 `-` / `=` 也可以用作“以词定字”的按鍵，已勾選用於翻頁的鍵組不能再選作以詞定字。

#### 輸入糾錯

全拼輸錯時給出糾正候選，兩項預設關閉。開啟後預編輯仍顯示原始輸入，糾正結果只出現在候選中。

- **亂序糾錯**：相鄰字母順序打錯時糾正，例如 `sahng` → `shang`（上）。
- **鄰鍵糾錯**：誤觸相鄰按鍵時糾正，例如 `shabg` → `shang`（上）。

#### 模糊音

開啟總開關後，勾選的兩個讀音互相匹配，例如勾選 `z ⇄ zh` 後輸入 `zhang` 也能命中 `zang` 開頭的詞，全拼和雙拼均生效。聲母可選 `z ⇄ zh`、`c ⇄ ch`、`s ⇄ sh`、`n ⇄ l`、`f ⇄ h`、`r ⇄ l`，韻母可選 `an ⇄ ang`、`en ⇄ eng`、`in ⇄ ing`、`ian ⇄ iang`、`uan ⇄ uang`。

#### 候選詞翻譯

開啟後，在橫排和直排候選字視窗中顯示候選與目標語種的互譯，每項最多兩個簡短釋義。釋義用於展示，送出文字內容仍是候選文字；候選字視窗顯示時按 `Ctrl + Enter` 可以改為送出反白候選右側的譯文，有多條譯文時會先列出供選擇。

目標語種可選英語、法語、日語、西班牙語、俄語、德語和韓語。英語優先使用本地詞庫，本地未命中時使用所選線上服務：騰訊雲 TMT 填寫 SecretId、SecretKey；小牛翻譯填寫 APP ID 和 API Key；自訂 DeepLX 填寫完整的 POST 介面地址和可選的 Bearer API Key。憑證只儲存在本機配置檔案中，填好後可以點選“测试配置”檢查。線上翻譯會把待翻譯候選傳送給配置的服務。

自訂本地釋義可寫入 `%LOCALAPPDATA%\metasequoiaime\custom_translations.txt`：UTF-8 文字，每行用 Tab 分隔源詞和譯文，例如“你好”、Tab、“hello”。源詞含漢字時為中譯英，全是英文時為英譯中。以 `#` 開頭的行和空行忽略；相同源詞以最後一條為準，優先於內建釋義。修改後重啟輸入法生效。

#### 以詞定字

開啟後，按所選鍵組的左鍵送出目前反白候選的第一個漢字，按右鍵送出最後一個漢字。鍵組可選 `[` / `]` 或 `-` / `=`，已勾選用於翻頁的鍵組不能選。遇到單字難找、但相關片語很容易輸入時，這個功能會比較順手。

#### Esc 保留已選詞

預設關閉。開啟後，造詞時第一次按 `Esc` 只清除還沒選的拼音、保留已選的詞，再按一次 `Esc` 才整體取消，與小狼毫的行為一致。

#### 固定標點狀態

可在“跟随中英文状态”“始终使用中文标点”和“始终使用英文标点”三者中選一項。選擇後兩項之一時，切換中英文輸入仍使用指定的標點狀態。

#### 智慧標點

在中文標點狀態下自動轉換標點。新安裝預設關閉；開啟總開關後，再按需開啟下面四項：

- **中文標點後按空格轉換**：輸入 `。，！？；：、` 以及單獨出現的 `“ ”`、`【 】`、`《 》`、`（ ）` 後按空格，轉為對應的英文標點。“成对标点自动补全”一起補出的成對符號不轉換。
- **同鍵轉回中文**：轉換或直出的英文標點，2 秒內再按同一標點鍵會轉回中文。
- **數字後直出**：數字後輸入 `,`、`.`、`:` 直接輸出英文標點，例如 `3.14`。
- **字母後直出**：字母後輸入 `,`、`.`、`:` 直接輸出英文標點。

#### 成對標點自動補全

輸入左側括號、引號等成對符號時，自動補上右側符號，並把游標放在兩者中間。

#### 常用輸入狀態和中文標點

- 按 `Ctrl + .` 可以在中文標點和英文標點之間切換，也可以點選懸浮工具列上的“中英文标点”。
- 按 `Ctrl + Shift + Space` 可以切換全形和半形字元。
- 在中文模式下按 `Ctrl + Shift + E`，可以進入或退出獨立的英文候選輸入模式。這個模式與下方的“中英混输”不同：中英混輸是在拼音候選中補充英文，英文候選模式則專門按英文詞庫匹配目前字母串。
- 中文標點狀態下，按反斜槓鍵 `\` 輸入頓號 `、`。這是頓號對應的直接按鍵，不需要先開啟符號面板。
- 其他常見對應關係包括：鍵盤左上角的反引號鍵輸入間隔號 `·`，`Shift + 6` 輸入省略號 `……`，`Shift + -` 輸入破折號 `——`，`Shift + ,` / `Shift + .` 輸入書名號 `《` / `》`。

已經有候選時，輸入中文標點通常會先送出文字目前反白候選，再緊跟標點。如果只是想取消目前輸入，請按 `Esc`。

#### 中英混輸

開啟後，在中文輸入狀態下也會根據字母串給出英文候選。觸發字元數可以設定為 `1`～`8`，預設為 `5`，達到設定長度後才補充英文候選，適合在中文句子中穿插英文單詞。

#### emoji 與顏文字混輸

分別開啟後，可在普通中文候選中補充匹配的 emoji 和顏文字。英文、emoji、顏文字依次排列；雲端候選字和 AI 候選也開啟時，附加項會順移。專門搜尋表情可使用 E、M 模式。

#### 預設中英文

決定啟動輸入法或從其他輸入法切回水杉輸入法時，預設進入中文還是英文狀態。

#### 中英文狀態

- **按應用記憶**：每個應用分別記住中文或英文狀態。例如可以讓編輯器保持英文、聊天視窗保持中文。
- **全域統一**：所有應用共用同一個中英文狀態，在一個應用裡切換後，其他應用也跟著變化。

#### 簡繁輸入

選擇“简体”時輸出簡體字，選擇“繁体”時將候選結果轉換為繁體字。

#### 雲端候選字

**這一項出廠預設是開啟的**，也是唯一一個不需要填任何金鑰、裝完就在聯網的功能，所以單獨說明：開啟狀態下，正在輸入的拼音串會透過 HTTPS 發往谷歌雲端候選字介面（`inputtools.google.com`）取一條候選。發出去的只有拼音串本身，不包含已送出文字的文字、詞庫內容、調頻資料或任何設定。雲端返回的內容如果不在目前本地候選中，會插入第一頁第 2 項。網路不可用時，本地輸入不受影響。

不希望任何輸入內容離開本機的話，在這裡關掉它，或把 `%LOCALAPPDATA%\metasequoiaime\config.toml` 的 `[general]` 段改成 `cloud_candidates = false`；首次安裝時也可以在“联网功能”頁取消勾選。完整的聯網清單見 [PRIVACY.md](https://github.com/metasequoiaime/msime-windows/blob/develop/PRIVACY.md)。

#### 整句候選

輸入多個拼音音節時提供整句候選，由本機的語言模型生成，不聯網。可以分別開關“Trigram 模型整句”“Unigram 模型整句”“神经网络模型整句（效果优先）”和“神经网络模型整句（速度优先）”：效果優先會結合已送出的前文，從最多 12 個備選句中選擇，處理時間較長；速度優先使用輕量模型。兩種神經網路模式可以同時開啟，各自給出結果。

- **去重後補充次選**：某個模型的首選與已有候選重複時，改為顯示該模型排名最高的下一條不同結果。
- **顯示整句來源標籤**：在整句候選後顯示〔Trigram〕〔Unigram〕〔神经D〕〔神经K〕等來源標籤，預設關閉。

#### 拼音方案調頻

調頻會根據實際選詞記錄改變候選順序。

- **調頻方式**：“关闭”不調整順序；“一次置顶”把觸發調頻的候選移到首位；“折半调频”把候選移到目前名次與首位之間；“线性调频”按固定步數向前；“一次置前”會讓前五名中的候選前移一位，排在第五名之後的候選則直接提到第五名。
- **觸發頻次（第幾次送出文字觸發）**：同一候選累計選中多少次後才調整一次，可選 `1`～`6`。數值越大，排序變化越穩。
- **線性調頻步長**：使用“线性调频”時，每次向前移動多少位，可選 `1`～`6`；其他調頻方式不會使用這個數值。

### 輔助碼

輔助碼是在完整拼音後追加的形碼，可以把同音候選縮小到更容易挑選的範圍。全拼和雙拼分別有獨立的開關、方案和顯示設定。

#### 雙拼輔助碼

- **雙拼輔助碼**：控制雙拼輸入時是否辨識輔助碼。
- **雙拼輔助碼方案**：可選藍天小雨點、自然碼、首右 2.0、首右 Plus、小鶴和拼音加加，也可以使用下文的自訂輔助碼。
- **在候選字視窗中顯示雙拼輔助碼**：開啟後，候選文字旁會顯示對應形碼，便於記憶和核對。

#### 全拼輔助碼

- **全拼輔助碼**：控制全拼輸入時是否辨識輔助碼。
- **全拼輔助碼方案**：可選藍天小雨點、自然碼、首右 2.0、首右 Plus、小鶴和拼音加加，也可以使用下文的自訂輔助碼。
- **在候選字視窗中顯示全拼輔助碼**：開啟後，在全拼候選文字旁顯示對應形碼。

#### 自訂輔助碼

把 UTF-8 編碼的 `.txt` 輔助碼檔案放進資料目錄下的 `helpcodes\custom` 資料夾，點選“刷新方案”後即可在上方方案中選擇；頁面提供“打开目录”入口。每行寫作 `字=輔助碼`；方案名預設取檔名，也可以在檔案開頭用 `# name: 中文名` 和 `# name_en: English name` 註解指定。修改正在使用的方案檔案後，需要切換一次方案或重啟輸入法才會生效。

#### 輔助碼怎麼輸入

輔助碼只有在前面的全拼或雙拼編碼已經完整時才會生效。如果拼音還沒有輸完整，末尾字母仍按普通拼音處理。

單碼輔助主要調整順序，不會丟掉其他候選：單字匹配該字的任意一個形碼，片語匹配首字或末字的首個形碼。在雙拼中，小寫單碼優先排列第一位匹配的候選，大寫單碼優先排列第二位匹配的候選；對單字，兩個位置是該字的兩個形碼，對片語則是首字和末字的首個形碼。雙碼輔助會嚴格篩選：單字分別匹配兩個形碼，片語分別匹配首字和末字的首個形碼。

以自然碼中輔助碼為 `ek` 的“阿”為例：

```text
全拼单码：aE
全拼双码：aEK
双拼单码：aae 或 aaK
双拼双码：aaeK、aaKe 或 aaKE
```

全拼追加的輔助碼需要使用大寫字母。雙拼單碼中，小寫表示第一輔助碼優先，大寫表示第二輔助碼優先。例如“阿”的輔助碼為 `ek`：`aae` 優先匹配第一碼 `e`，`aaK` 優先匹配第二碼 `k`。

雙拼雙碼輔助的大小寫規則如下：

| 第一碼 | 第二碼 | 結果                 |
| ------ | ------ | -------------------- |
| 小寫   | 小寫   | 不觸發雙碼輔助       |
| 小寫   | 大寫   | 觸發，按正常順序匹配 |
| 大寫   | 小寫   | 觸發，按反轉順序匹配 |
| 大寫   | 大寫   | 觸發，按反轉順序匹配 |

當第一碼為大寫時，第二碼無論大小寫都會觸發雙碼輔助，輸入順序按“第二辅助码 → 第一辅助码”解釋。因此 `Ke` 和 `KE` 都可以反向匹配實際輔助碼 `ek`。

片語的用法相同。例如：

```text
全拼：ayiE / ayiEN
双拼：aayie / aayiN / aayieN / aayiNe / aayiNE
```

### 快捷鍵

#### 簡繁切換

`Ctrl + Shift + F` 在簡體和繁體輸出之間切換，預設啟用，可在這裡取消勾選。僅在中文輸入狀態生效，切換時保留正在輸入的內容。

#### 中英文切換

可以分別啟用 `Shift`、`Ctrl` 和 `Ctrl + Alt + Space`。這些快捷鍵只負責水杉輸入法內部的中英文切換。

`Ctrl + Space` 由 Windows 管理，不受這裡的開關控制。如需修改，請進入 Windows“设置 → 时间和语言 → 输入 → 高级键盘设置 → 输入语言热键”，選中“中文（简体）输入法 - 输入法 / 非输入法切换”後更改按鍵順序。不同 Windows 版本的文字可能略有不同；修改後未立即生效時，可以重新登入或重啟電腦。

#### 候選操作

- `Space` 或 `1`～`9`：選擇候選。
- `-` / `=`、`,` / `.`、`Shift + Tab` / `Tab`、`Page Up` / `Page Down`：候選翻頁。是否生效由“输入 → 翻页方式”中的勾選項決定。
- `↑` / `↓`：移動候選項。
- `←` / `→`、`Backspace`：移動游標或修改輸入字串。
- `Enter`：提交原始輸入；`Esc`：取消本次輸入。

組詞時還可以用 `Ctrl + ←` / `Ctrl + →` 按分詞移動游標，用 `Ctrl + Backspace` 刪除前一個拼音分段；已經選了部分詞時，`Backspace` 會先撤銷最近一次選的詞。開啟“候选词翻译”時，`Ctrl + Enter` 送出反白候選的譯文。

#### 全域快捷鍵

以下快捷鍵在輸入法服務執行期間全域生效，主要用於維護和排查問題：

- `Ctrl + Shift + Alt + 1`～`8`：刪除目前候選字視窗中對應位置的候選項。
- `Ctrl + Shift + Alt + C`：清除輸入法引擎快取。
- `Ctrl + Shift + Alt + R`：重啟輸入法服務。
- `Ctrl + Shift + Alt + T`：立即退出輸入法服務。退出後需要重新啟動服務才能繼續使用。

### 詞庫

#### 查詢和維護詞條

頂部可以切換全拼詞庫、五筆詞庫和英文詞庫。

- **全拼詞庫**：輸入完整拼音查詢，例如 `nihao`。新增詞條時填寫拼音、詞條和權重，拼音可以用 `'` 分隔音節，例如 `ni'hao`。
- **五筆詞庫**：按五筆編碼查詢或新增詞條。
- **英文詞庫**：按英文字首查詢。新增或編輯時填寫檢索用的單詞、候選字視窗中的顯示內容和權重。

查詢結果每頁顯示 100 條，可用“上一页”“下一页”翻看。結果列表中的“编辑”和“删除”可以修改或移除使用者詞條；權重越高，通常越靠前。

#### 批次匯入

頂部的“批量导入”支援全拼、五筆和英文詞庫。請選擇 **UTF-8** 純文字（`.txt`），可帶 BOM；帶 BOM 的 UTF-16 和 GBK 編碼的檔案也能識別；換行用 LF 或 CRLF 都可以。空行會被忽略；全拼和五筆詞庫還會跳過以 `#` 開頭的註解行，英文詞庫不支援註解行，請不要在英文匯入檔案中寫註解。**檔案不要新增表頭**；下面程式碼塊只包含資料行，列之間為真正的 Tab。

列與列之間**只能使用 Tab**（`\t`），不能用空格、逗號或分號。詞語裡可以包含空格。已存在的詞條會跳過，不會覆蓋原有權重。

目前**不能直接匯入**搜狗細胞詞庫（`.scel`）或搜狗匯出的 `词语,拼音` 逗號分隔文字。請先轉成下面的水杉格式再匯入。如果需要讓 AI 幫忙轉換，把本節規範連同原始檔案一起發給它即可。

Rime 的詞庫可以直接匯入：全拼詞庫接受 `userdb.txt` 和 `.dict.yaml`，五筆詞庫接受 `.dict.yaml`，選擇檔案時可選 `.yaml` / `.yml`。檔案開頭的 YAML 段落和註解會被跳過，`userdb.txt` 第三列的 `c=…` 統計資訊不作為權重，按預設權重匯入。

##### 全拼詞庫

每行兩列或三列，順序固定為 **詞語、全拼、權重**：

```text
你好	ni'hao	10
西安	xi'an	10
水杉输入法	shui'shan'shu'ru'fa	1
```

- 全拼必須是拼音表中的**完整音節**，不能用簡拼。
- 推薦用 `'` 手動分音節，例如 `ni'hao`、`xi'an`。不寫 `'` 時（包括 Rime 詞庫中用空格分隔的 `ni hao`），空格會被去掉，輸入法按完整音節和詞語字數自動切分，例如 `西安` 的全拼寫 `xian` 時會按兩個字切成 `xi'an`；但像 `fangan` 這樣按字數仍有多種切法（`fang'an` 或 `fan'gan`）的拼音，請手動寫 `'`。
- 音節數量必須與詞語的字數一致。
- 權重必須是非負整數，可以省略，省略時為 `10000`。

##### 五筆詞庫

每行兩列或三列，順序為 **詞語、五筆編碼、權重**：

```text
你好	wbgq	10
```

編碼只能是英文字母；匯入時會轉成小寫。權重同樣必須是非負整數，可以省略，省略時為 `30`。

##### 英文詞庫

每行兩列或三列，順序為 **單詞、顯示內容、權重**：

```text
meta	meta	10000
github	GitHub	15000
```

單詞只支援英文字母、連字元和撇號，匯入後會轉成小寫；顯示內容會出現在候選字視窗中，可以保留大小寫。權重可以省略，以相容舊版匯出的兩列檔案；省略時權重為 `0`。

##### 純漢字片語

“批量导入纯汉字词组”適合人名等只有漢字、沒有現成編碼的文字，全拼詞庫和五筆詞庫頁各有一個入口。檔案中每行放一個片語，不要寫編碼或權重。在全拼詞庫頁匯入時，輸入法自動產生拼音並加入全拼詞庫，權重為 `10000`；在五筆詞庫頁匯入時，按 86 五筆片語取碼規則產生編碼並加入五筆詞庫，權重為 `30`。

##### 給 AI 或指令碼生成檔案

請生成 UTF-8 文字，每行一條，列之間用真正的 Tab 字元分隔，不要用空格或逗號。全拼、五筆和英文都可以是兩列或三列，建議寫上權重。全拼列請儘量帶 `'` 分音節，並保證音節數等於漢字數。不要輸出搜狗的 `词语,拼音` 格式。

#### 匯出詞庫

可以分別匯出拼音、五筆和英文使用者詞庫。匯出檔案與上面的匯入格式相同，適合備份、遷移或整理後重新匯入。快捷片語使用者詞庫的匯出入口在“实用功能 → 快捷短语”。

### 佈景主題

內建佈景主題包括 Fluent、微信綠、石墨 Graphite、楊柳青 Willow green、秋桂 Autumn osmanthus 和微軟 Microsoft，可以在頁面選擇啟用。“预览浅色 / 预览深色”只切換預覽效果，不會改動“外观”中的實際主題。下方依次展示橫排候選字視窗、直排候選字視窗和懸浮工具列效果。

外部佈景主題：把包含 `skin.toml` 的佈景主題資料夾放入 `%LOCALAPPDATA%\metasequoiaime\skins`，再點選“刷新皮肤”。頁面提供“打开目录”入口；無法載入時檢視頁面診斷資訊。佈景主題編寫說明見[佈景主題示例儲存庫](https://github.com/metasequoiaime/msime-skin-example)。

### 語音輸入

Windows 語音輸入使用配置好的網路服務。目前設定提供豆包、OpenAI、SiliconFlow 和 Groq 的辨識配置，文字潤色可以單獨選擇服務。請按所用服務填寫介面、模型和憑證；帳戶需具有對應介面權限。

#### 啟用語音輸入

總開關。開啟後，可以在輸入法右鍵選單中點選“语音输入”開始或停止錄音。

#### 語音輸入快捷鍵

- **RAlt（長按錄音）**：按住右 `Alt` 開始，鬆開後停止並辨識。
- **Ctrl + Win（長按錄音）**：先按住 `Ctrl`，再按 `Win` 開始；鬆開後停止。
- **RCtrl + RAlt（長按錄音）**：先按住右 `Ctrl`，再按右 `Alt` 開始；鬆開後停止。
- **長按快捷鍵 + Space（鎖定錄音）**：錄音時按空格鎖定，隨後鬆開長按鍵也不會停止。
- **Ctrl + F9（開始 / 停止錄音）**：按一次開始，再按一次停止並辨識；也可以用它結束已經鎖定的錄音。

錄音過程中按 `Esc` 會取消本次錄音，不提交辨識結果。組合快捷鍵請按“先修饰键、后触发键”的順序操作。

#### ASR API

- **服務提供商**：選擇 `doubao`、`openai`、`siliconflow` 或 `groq`。豆包使用流式辨識，其餘使用語音轉寫介面。
- **API Token**：填寫所選提供商的訪問權杖，各提供商分別儲存。請勿分享包含憑證的配置檔案或截圖。
- **介面地址與模型**：使用所選提供商的對應值，不能拿其他提供商的 Token 代替。
- **豆包鑑權方式**：“新版控制台 API Key”只需填寫 API Key；“旧版控制台 App ID”需要填寫 App ID 和 Access Token。

豆包另有“流式接口”選項：整句流式邊錄邊傳、說完返回整句，準確率更高；雙向流式返回增量結果，重新整理更頻繁；選擇後會同步寫入介面地址。還可以設定數字格式化、標點預測、語義順滑和熱詞表 ID；熱詞表需先在豆包語音自學習平臺建立。語義順滑與文字潤色同時開啟時，可能產生二次改寫。

#### 文字潤色 API

開啟後，語音辨識結果會傳送給單獨配置的文字服務整理，然後送出文字。如果只需要原始辨識結果，可以關閉此項。

- **服務提供商**：可選 `siliconflow`、`openai`、`deepseek` 或 `groq`。
- **API Token**：填寫可呼叫所選文字模型的 Token，潤色配置與辨識配置獨立。
- **介面地址與模型**：填寫所選文字服務的聊天補全介面和模型。潤色會傳送轉寫文字，關閉後直接使用辨識結果。

潤色預設包括精煉整理、忠實校對、中翻英、口語整理，並提供三套自訂提示詞。按希望輸出的文字形式選擇；翻譯類預設會改變輸出語言。

#### 基礎設定

- **辨識語言**：可選簡體中文、English 或自動。語言明確時直接選擇對應項，通常比自動判斷更穩定。
- **辨識結果的輸入方式**：`TSF 上屏` 走輸入法框架提交文字，通常優先使用；`SendInput` 模擬鍵盤輸入；`Ctrl+V 上屏` 透過剪貼簿貼上。遇到某個應用無法正常接收結果時，可以嘗試另外兩種方式。
- **錄音提示音**（位於頁面上方）：總開關下可以分別設定開始錄音和結束錄音時是否播放提示音。

豆包流式辨識可以啟用“流式 inline 预编辑”，將已辨識文字直接顯示在輸入框中，鬆開錄音鍵後送出文字；僅 TSF 送出文字方式生效。“录音时静音其他声音”會暫時關閉其他應用的播放聲音，並在錄音結束後恢復。

點選“打开”啟動螢幕小鍵盤，可以用滑鼠或觸控輸入文字和快捷按鍵。下方圖片用於預覽介面；螢幕小鍵盤的深淺色在“外观 → 屏幕键盘主题”中設定。

### 手寫辨識板

點選“打开”啟動手寫辨識板。用滑鼠或觸控書寫後，辨識結果會以候選漢字顯示；點選候選可將其複製到剪貼簿，再貼上到需要的位置。下方是介面預覽；深淺色在“外观 → 手写识别板主题”中設定。若沒有辨識結果，請確認 Windows 已安裝中文手寫包。

### 實用功能

下面的字母快捷模式在中文狀態、沒有正在輸入的組詞時進入，並由各自開關控制。

#### 剪貼簿管理

開啟後，複製過的文字顯示在表情面板的剪貼簿分頁中；只記錄文字。關閉功能會立即清空記錄，複製敏感內容前可先關閉。

#### 快捷片語（K 模式）

開啟後，在中文狀態下按 `Shift + K` 進入快捷片語模式，再輸入編碼即可呼叫短語。編碼只能包含英文字母，觸發鍵 `K` 本身不屬於編碼。

“快捷短语混入候选”預設關閉。開啟後，在全拼或雙拼下輸入的編碼與快捷片語的編碼完全一致時，快捷片語直接出現在候選首位（固定位置的候選之後），不用按 `Shift + K`；五筆不支援。“快捷短语参与调频”預設開啟：經常越過快捷片語選別的候選時，它會往後退，最多退到首頁最後一位；關閉後快捷片語始終在首位。

搜尋框按編碼字首查詢，留空可以檢視全部。點選“新增短语”填寫編碼、短語和權重；已有短語可以編輯或刪除。權重較高的短語會優先顯示。

“批量导入”接受 UTF-8 純文字，每行一條，不加表頭，用真正的 Tab 分隔，格式與匯出檔案相同：

```text
mail	example@example.com	10
```

權重可以省略。編碼只能是英文字母，重複條目會被跳過。下方的“导出快捷短语用户词库”用於備份使用者新增的短語。

#### 日期與時間快捷輸入（T 模式）

開啟後，在中文狀態下按 `Shift + T` 進入該模式：

- 輸入 `rq`、`riqi` 或 `date`，選擇目前日期。
- 輸入 `sj`、`shijian` 或 `time`，選擇目前時間。
- 輸入 `xq`、`xingqi` 或 `week`，選擇目前星期（中文與英文）。

#### Unicode 便捷錄入（U 模式）

開啟後，在中文狀態下按 `Shift + U`，再輸入 Unicode 十六進位制碼位，例如 `4e00` 或 `+1f600`。按空格送出首選結果；需要選擇其他候選時，使用 `Shift + 数字`。

#### Emoji（E 模式）與顏文字（M 模式）

在中文狀態、沒有正在輸入的組詞時，按 `Shift + E` 搜尋 emoji，按 `Shift + M` 搜尋顏文字。支援全拼、簡拼、雙拼或英文關鍵詞，例如 emoji 的 `xiaolian` / `xl` / `laugh`、顏文字的 `haixiu` / `kiss`。按空格選擇反白結果，`Esc` 取消；可分別關閉這些入口。

#### 超級簡拼（J 模式）

開啟後，在中文狀態下按 `Shift + J` 進入超級簡拼：之後輸入的每個字母都按簡拼檢索詞庫，而不會被切成完整音節。全拼例如 `nh` 得到「你好」，`an` 得到兩字詞而不是「安」。雙拼會按目前方案把鍵轉換成聲母，因此小鶴 `u` / 自然碼 `u` / 微軟 `u` 對應 `sh`：`nu` 匹配 `n'sh`（你說），`ns` 匹配 `n's`，兩者不會混在一起。空格送出首選；數字選詞。調頻、置頂規則與全拼 / 雙拼相同。

#### 臨時英文（Y 模式）

開啟後，在中文狀態下按 `Shift + Y` 進入臨時英文：之後輸入的字母按英文處理，不會當作拼音。空格送出目前輸入；數字可選英文詞庫中的單詞。送出文字後自動回到中文輸入。

#### 臨時日語（R 模式）

開啟後，在中文狀態、沒有正在輸入的組詞時按 `Shift + R`，再輸入日語羅馬字。空格選擇首選，數字選擇其他候選；送出文字後回到中文。

### AI 輔助

#### 啟用 AI 聯想

開啟後，全拼和雙拼輸入會非同步請求所選 AI 服務。返回內容如果不與本地或雲端候選字重複，會插入第一頁第 3 項。請求需要網路，介面異常時不會影響本地候選。目前可選 DeepSeek、OpenAI、SiliconFlow 和 Groq，使用相容 Chat Completions 的介面。

#### API 配置

- **服務提供商**：可選 `deepseek`、`openai`、`siliconflow` 或 `groq`。
- **模型**：填寫所選服務實際支援的模型名稱。若沒有特殊需要，沿用安裝版本給出的預設值。
- **API Token**：填寫所選服務的 API Token，各提供商分別儲存在本機配置中，不要公開配置檔案或截圖。
- **候選數量**：告訴模型最多生成多少條結果，範圍為 `1`～`10`。目前輸入法會採用返回結果中的第 1 條，因此這個數值主要用於約束介面輸出。
- **介面地址**：填寫所選服務的完整對話補全介面。例如 DeepSeek 使用 `https://api.deepseek.com/chat/completions`；更換提供商後一起核對模型、介面和 Token。

#### 自訂提示詞

可以儲存並切換三套自訂提示詞。提示詞用來規定模型怎樣根據拼音、上下文和候選數量生成結果。修改時應保留“按拼音对应候选”和“只返回约定 JSON 结构”這類約束，否則可能出現候選讀音不符或介面結果無法解析的問題。

### 懸浮工具列

#### 在桌面顯示懸浮工具列

控制桌面懸浮工具列是否顯示。工具列用於檢視輸入狀態並快速開啟常用功能，下方區域會預覽目前效果。

#### 自動隱藏工具列

預設關閉。開啟後，工具列在設定的延時（`1`～`60` 秒，預設 `5` 秒）內沒有互動就會淡出；滑鼠停在工具列上時不會隱藏，切換中英文、全半形、標點等狀態時重新顯示。

#### 游標狀態提示

在文字游標附近短暫顯示輸入法狀態，可與懸浮工具列同時開啟，兩項開關預設關閉：

- **切換輸入法狀態時提示**：切換輸入模式、全半形或中英文標點時顯示。
- **切換輸入框時提示**：焦點移到另一個輸入框時（包括同一視窗內和其他視窗中的），也提示目前中英文狀態。
- **提示位置**：可選游標的左上方、正上方、右上方、左下方、正下方或右下方。

#### 工具列外觀

- **工具列縮放**：可選 `75%`、`100%`、`125%`、`150%`。這是相對於 Windows DPI 的額外縮放，不會改變系統顯示設定。
- **圖示尺寸**：可選 `16`～`28` 像素，最終顯示大小還會乘以上面的工具列縮放比例。

#### 工具列元件

中英文切換始終顯示，不能取消。其餘可按需勾選：全形 / 半形、中英文標點、簡繁切換、表情與符號、螢幕小鍵盤和設定。取消勾選只會隱藏工具列入口，不會關閉對應功能。

### 統計

“启用输入统计”預設關閉。開啟後只在本機記錄每天、每小時各類字元（中文、英文字母、數字、標點和其他）的數量與活躍時長，不記錄輸入內容，也不聯網；中文和英文模式都會記錄。頁面顯示輸入速度、近 12 個月的日曆熱力圖、今日時段分佈、字元分類和最近 30 天的按日明細。輸入速度按可讀字數（中文加英文）除以活躍分鐘計算，數字和標點不計入，相鄰送出文字間隔不超過 10 秒計為活躍。

“自动清理”可選永久保留或保留最近 30、90、180、365 天，超期記錄在跨天後首次寫入統計時刪除；“清空统计数据”會立即刪除全部記錄（包括今天），無法恢復。關閉開關後停止記錄，已有資料繼續保留。統計資料儲存在資料目錄的 `stats.db` 中，頁面提供“打开数据目录”入口。

### 幫助

幫助頁提供一份內建的快速說明，包括系統要求、切換輸入法的方法、輸入方案、輔助碼以及聯網功能的基本提醒。遇到具體配置問題時，可以再對照本文對應功能區檢視。

## 更新、備份與故障排查

更新前在“词库”中分別匯出全拼、五筆和英文使用者詞庫，並在“实用功能”匯出快捷片語。匯出詞條不等於備份全部配置；本機配置位於 `%LOCALAPPDATA%\metasequoiaime\config.toml`，其中的 API Token 等服務憑證以明文儲存，備份請自行保管；學到的詞頻和使用者造詞儲存在同一目錄的 `msime_user.db`。更新使用官網或 Release 提供的安裝套件覆蓋安裝，按對應發布說明操作，覆蓋安裝會保留使用者詞庫、配置、佈景主題和統計資料。解除安裝可從 Windows“已安装的应用”進入；解除安裝會刪除資料目錄中的使用者詞庫、配置等資料，重要詞條請先匯出。

- **候選字視窗或設定頁空白**：確認 Server 正在執行，檢查 Microsoft Edge WebView2 Runtime 是否安裝；參照安裝版本的發布說明排查。
- **只有特定應用不能送出文字**：先在記事本重現並對比，記錄宿主程式及版本、是否以管理員身份執行、所用輸入模式。
- **匯入部分失敗**：按返回的行號檢查 Tab、列數、權重和拼音音節數；修正失敗行後重新匯入，已存在條目會跳過。
- **聯網功能失敗**：先關閉相應聯網功能確認本地輸入正常，再核對網路、服務地址、模型和憑證；AI 輔助、語音輸入和候選詞翻譯的配置旁都有“测试配置”按鈕。不要在公開回報中貼上 Token。

雲端候選字會傳送拼寫，AI 聯想會傳送用於生成候選的拼寫與上下文，線上翻譯會傳送候選，語音辨識會傳送音訊，潤色會傳送轉寫文字，檢查更新只在點選時請求版本資訊。需要離線輸入時，關閉這些聯網選項；本地詞庫輸入、整句候選和輸入統計都在本機完成。

## 專案結構

Windows 版的全部一方原始碼都在 [msime-windows](https://github.com/metasequoiaime/msime-windows) 一個儲存庫裡，一次 clone 就能構建完整產品：

- [windows/](https://github.com/metasequoiaime/msime-windows/tree/develop/windows)：TSF 文本服務 DLL，負責按鍵預判、焦點和與 Server 之間的管道協議。
- [server/](https://github.com/metasequoiaime/msime-windows/tree/develop/server)：常駐 Server，負責引擎排程、候選字視窗與工具列的宿主、設定程式和詞庫管理。
- [engine/](https://github.com/metasequoiaime/msime-windows/tree/develop/engine)：輸入引擎，包括輸入會話、候選查詢、輔助碼和語音模組。源自已歸檔的 msime-engine，現在隨 Windows 版一起開發。
- [ui/](https://github.com/metasequoiaime/msime-windows/tree/develop/ui)：自研原生 GUI 框架，Win32 視窗加 Direct2D / DirectWrite 渲染。
- [ui-html/](https://github.com/metasequoiaime/msime-windows/tree/develop/ui-html)：WebView2 介面資源，包括候選字視窗、懸浮工具列、托盤選單和設定頁。
- [installer/](https://github.com/metasequoiaime/msime-windows/tree/develop/installer)：Inno Setup 安裝器。

相關儲存庫：

- [msime](https://github.com/metasequoiaime/msime)：多平臺主儲存庫，包含 macOS、iOS、Linux、Android 與 HarmonyOS 的前端，以及它們共用的 Rust 輸入引擎。儲存庫裡的 Windows 宿主仍在開發中，沒有發布；目前發布的 Windows 版來自 msime-windows。
- [msime-dictionary](https://github.com/metasequoiaime/msime-dictionary)：詞庫源資料，包括基礎詞庫、人工維護的詞條與專業詞庫。
- [msime-cloud](https://github.com/metasequoiaime/msime-cloud)：雲端候選字、AI 聯想、翻譯與語音辨識的後端。目前發布的 Windows 版不經過它：雲端候選字直接請求谷歌，AI 聯想、翻譯和語音辨識直接請求你填寫的服務商。
- [msime-skins](https://github.com/metasequoiaime/msime-skins)：候選字視窗佈景主題。

msime-engine、msime-linux、MSIME-UI、MSIME-UiHtml、MSIME-Windows-Server、MSIME-Installer 等舊儲存庫已經歸檔，保留歷史提交紀錄和已發布的 Release。

文件會隨功能繼續更新。如果發現說明和實際行為不一致，歡迎在 [GitHub Issues](https://github.com/metasequoiaime/msime-windows/issues) 中回報。
