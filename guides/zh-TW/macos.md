# macOS 使用指南

水杉 macOS 前端使用原生輸入法介面，支援 macOS 12 及以上版本。本文按 2026-09-06 的 Apple 原始碼整理；安裝套件功能以對應 Release 為準。iOS 鍵盤仍在開發中，不能用 macOS 安裝套件安裝到 iPhone 或 iPad。

本頁採用臺灣繁體中文用語；引號內的應用程式選項、程式碼、檔名與範例保留原文，方便對照實際介面。

## 下載與安裝

從 [Apple Releases](https://github.com/metasequoiaime/MSIME-Apple/releases) 下載對應版本的 macOS universal ZIP 或 PKG。universal 套件面向 Apple Silicon 與 Intel Mac。檔名中的 `-update.zip` 是自動更新載荷，手動安裝請選擇普通 ZIP 或 PKG。

1. 下載歸檔及同名 `.sha256` 檔案，在下載目錄用 `shasum -a 256 -c 文件名.sha256` 校驗；把“文件名”替換為實際下載名稱。
2. ZIP 解壓後執行其中的 `Install.command`；PKG 則雙擊進入系統安裝器。兩種方式都安裝到目前使用者的 `~/Library/Input Methods`，PKG 可能請求管理員授權。
3. 安裝器會嘗試註冊並啟用輸入法。未出現時，到“系统设置 → 键盘 → 文本输入 → 编辑”中新增水杉；較舊系統的入口名稱可能不同。
4. 在選單欄輸入源中選中水杉，開啟文字框輸入 `nihao`，按空格選詞。

帶 `-unsigned` 的包是明確標註的未簽名測試產物。按發布說明和系統提示處理；ZIP 安裝器可能要求輸入 `I UNDERSTAND`。如果系統仍未重新整理輸入源，儲存工作後登出並重新登入。

## 常用操作

| 操作 | 按鍵或入口 |
| --- | --- |
| 選擇候選 | 空格選首選；`1`～`9` 選擇對應候選，也可點選候選 |
| 提交原始字母 | `Enter` |
| 修改或取消 | `Backspace` 退格；`Esc` 取消 |
| 中英文切換 | `Shift + Space`，或輸入法選單；快捷鍵可在設定關閉 |
| 半形／全形 | `Option + Shift + H` |
| 簡體／繁體 | 輸入法選單或懸浮狀態列 |
| 翻頁 | 在設定選擇 `-` / `=`、`[` / `]` 或 Page Up / Page Down |

切換到英文時會先送出正在組合的中文字詞，後續按鍵直接交給應用。全形模式主要轉換未組詞時輸入的 ASCII 字母、數字、標點和空格。簡繁轉換改變候選展示和送出的文字，不改寫詞庫鍵值。

## 設定與候選字視窗

透過輸入法選單、懸浮狀態列齒輪，或發布 ZIP 中的 `Open Settings.command` 開啟設定。常用選項包括：

- **輸入方案**：全拼、小鶴雙拼、86 五筆；五筆可配置唯一四碼候選自動送出文字。
- **候選外觀**：橫排／直排，每頁 5、7 或 9 項，小／標準／大號字型。
- **雙拼鍵位提示**：顯示小鶴鍵位和零聲母對照；送出文字或取消後隱藏。
- **輔助碼**：全拼和雙拼分別設定開關與方案，可選藍天小雨點、自然碼、首右 2.0、首右 Plus、小鶴；候選旁顯示輔助碼提示。
- **輸入行為**：全拼糾錯、中文標點、詞頻學習以及懸浮狀態列顯示。

設定按目前使用者儲存。正在進行的組詞沿用開始時的設定，新設定在送出文字或取消後用於後續輸入。輔助碼追加在完整拼寫之後；初次使用建議先開啟提示，再練習完整拼寫加形碼的輸入方式。

## 本地快捷模式

在“词库与数据”中開啟“启用本地输入模式”（預設關閉），全拼或雙拼下無活動組詞時可使用：

| 快捷鍵 | 用途 | 示例 |
| --- | --- | --- |
| `Shift + U` | Unicode 碼點 | `4e00` 對應“一” |
| `Shift + T` | 日期、時間、星期 | `rq`、`sj`、`xq` |
| `Shift + K` | 快捷片語 | 輸入詞庫中已有的字母編碼 |
| `Shift + J` | 超級簡拼 | `nh` 檢索“你好”等候選 |

關閉總開關時，這些組合照常輸入大寫字母。目前 macOS 安裝套件不附帶額外表情、英文和日語資料，因此不要照搬 Windows/Linux 的 E、M、Y、R 模式。表情可透過輸入法選單或工具選單開啟 macOS“表情与符号”檢視器。

## 語音與資料

錄音配置、`Control + Option + V` 快捷鍵、取消操作和麥克風權限見 [macOS 語音輸入](macos-voice.md)。雲端辨識上傳音訊，本地 Whisper 使用使用者選擇的模型；開啟文字整理後，轉寫文字仍會發往整理服務。

普通鍵盤輸入與候選學習在本機處理。學習資料和可寫詞庫位於 `~/Library/Application Support/metasequoiaime/`，設定儲存在目前使用者的 macOS 偏好設定中。關閉候選學習只影響後續組詞；“清除学习数据”會清除本地學習資料庫並恢復隨包詞庫，請先確認不再需要這些記錄。備份資料目錄前先切換到其他輸入法並退出水杉，避免複製正在寫入的資料庫。語音金鑰在鑰匙串中，不包含在普通資料目錄備份內。

## 更新與解除安裝

輸入法選單和設定面板均有“检查更新…”入口。自動更新使用 Sparkle；普通 ZIP、PKG 與自動更新載荷的區別見前面的安裝說明。更新失敗時保留錯誤資訊，到同一官方 Release 頁面核對安裝版本與可用產物。

解除安裝使用發布 ZIP 中的 `Uninstall.command`；PKG 安裝後也可執行：

```sh
"$HOME/Library/Input Methods/MetasequoiaIME.app/Contents/Resources/Uninstall.command"
```

預設將目前使用者的輸入法移入垃圾桶，保留偏好與學習資料。指令碼要求輸入 `REMOVE METASEQUOIAIME` 確認。只有確實要移除資料時才加 `--remove-user-data`；該選項會將偏好和學習資料一併放入垃圾桶中的恢復資料夾。完成後登出，讓系統重新整理輸入源快取。

## 常見問題與回報

- **輸入源未出現**：確認安裝在目前登入使用者目錄，檢查系統是否攔截應用，在文字輸入設定中手動啟用，必要時登出登入。
- **快捷鍵輸入大寫字母**：確認本地輸入模式已開啟，且目前沒有未完成的組詞。
- **設定沒有立即生效**：先送出文字或取消目前組詞，再重新輸入。
- **語音無結果**：檢查麥克風權限、裝置、模型或服務配置；移動游標、繼續鍵盤輸入或切換視窗會取消請求。

問題提交到 [Apple Issues](https://github.com/metasequoiaime/MSIME-Apple/issues)，附 macOS 與輸入法版本、晶片架構、宿主應用和最小重現步驟。共享材料前移除實際輸入內容和憑證。更完整的資料說明見 [Apple 隱私說明](https://github.com/metasequoiaime/MSIME-Apple/blob/main/PRIVACY.md)。
