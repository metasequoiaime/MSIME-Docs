# macOS 語音輸入

本頁適用於 v0.44.0 起的 macOS 發布版（核對到 v0.50.0-build.11），這些版本的輸入法選單包含「語音輸入設定…」。[msime](https://github.com/metasequoiaime/msime) 的 `develop` 分支已把語音輸入改為在共用設定頁配置，辨識服務、本地模型和錄音時長都與本頁不同，這些改動尚未發布。iOS 不允許鍵盤直接錄音：iOS 測試版需要先在水杉 App 裡錄音辨識，再回到鍵盤插入結果，不在本頁範圍。

本頁採用臺灣繁體中文用語；引號內的應用程式選項、程式碼、檔名與範例保留原文，方便對照實際介面。

安裝、日常輸入和資料管理見 [macOS 使用指南](macos.md)。

## 配置

在水杉輸入法選單開啟「語音輸入設定…」，選擇雲端辨識或本地 Whisper。

- 雲端：填寫相容語音轉寫介面的 HTTPS 地址、模型名稱和 API 金鑰。
- 本地：選擇已下載的 Whisper 模型檔案。模型由使用者自行準備，輸入法不會自動下載。
- 文字整理：按需單獨開啟並填寫整理服務、模型和金鑰。即使辨識使用本地模型，啟用整理後仍會將轉寫文字傳送到整理服務。

金鑰儲存在系統鑰匙串中，按服務來源區分；修改服務地址後需要重新填寫金鑰。儲存設定後，回到需要輸入文字的應用並切換到水杉。

## 錄音與文字輸入

按 Control+Option+V 開始錄音，再按一次結束並辨識；也可使用輸入法選單中的「开始/结束语音输入（⌃⌥V）」。第一次使用會請求麥克風權限。錄音最長 60 秒，辨識完成後文字插入原來的輸入位置。

按 Esc、繼續鍵盤輸入、點擊滑鼠或切換輸入視窗會取消本次請求。游標位置改變後，遲到的結果也不會插入新位置。已經開始的本地 Whisper 推理可能繼續計算，但取消後不會提交結果。

## 資料與權限

錄音在本次請求的記憶體中儲存，不生成錄音檔案。雲端辨識會上傳本次音訊，文字整理會上傳轉寫文字；服務收到的資料無法透過取消操作收回。

如果無法錄音，請在 macOS 系統設定的「隱私與安全性 → 麥克風」中檢查水杉的權限，並確認有可用錄音裝置。辨識失敗時檢查所選模型檔案或服務地址、模型名稱及帳戶權限。隱私詳情見 v0.50.0-build.9 的[隱私說明](https://github.com/metasequoiaime/msime/blob/v0.50.0-build.9/PRIVACY.md)；`develop` 分支的 [PRIVACY.md](https://github.com/metasequoiaime/msime/blob/develop/PRIVACY.md) 描述的是尚未發布的新實作。
